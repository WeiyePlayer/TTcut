# TTcut v1.2.7

**简体中文** | [English](release-notes-v1.2.7.en.md)

`v1.2.7` 是 TTcut 1.2 功能线的正式版本，重点完善自定义剪辑页面，并修复自定义导出流程中的交互和校验问题。

## 自定义剪辑页面

- 重新整理自定义剪辑工作区、视频监视器、回合列表和紧凑导航，让查看、选择和编辑回合的操作更集中。
- 新增回合滚动操作，优化短片段编辑和长回合列表浏览。
- 自定义时间轴支持手动新增回合片段。新建片段从当前位置创建为一秒，并按时间重新排序；手动片段的板数会根据片段范围内的弹跳事件更新。
- 支持删除手动新增的回合片段，同时保留已识别回合的编辑和选择能力。

## 导出安全与交互修复

- 导出选项面板在指针从触发控件移动到面板时保持打开，修复意外关闭导致无法选择导出方式的问题。
- 导出前会分别验证手动和已识别回合的来源、标识、范围、顺序及重叠关系；不合法的选择会在开始处理前被拒绝。
- 合并视频、逐回合视频和 Premiere XML 继续共用同一套已验证的片段序列。合法相接的片段仍可按既有规则合并。
- 修复旧版安装迁移在缺少系统哈希命令的兼容 PowerShell 环境中无法完成备份校验和回滚的问题。

## 范围说明

- 本版本主要改进自定义页面、手动回合编辑和导出边界校验；不改变模型权重、球识别、回合识别、板数识别或动态 ROI 算法。
- 既有的合并 MP4、逐回合 MP4 和 Premiere 可导入 XML 导出方式继续保留。
- 安装包继续使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单。未信任该证书的 Windows 环境仍可能显示“未知发布者”或 SmartScreen 提示。

## 验证

- `npm run typecheck` 通过；串行 Vitest：44 个文件通过、218 个测试通过、17 个跳过。
- Worker 测试：64 个通过；官网构建和渲染测试均通过。
- 真实视频端到端流程通过：分析、时间轴缩放与滚动、手动新增/删除回合、片段调整、导出及预览均已验证。
- 正式安装包签名、更新清单签名和发布资产校验已在发布前完成。
