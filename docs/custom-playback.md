# 自定义页面的播放模式

## 自定义操作指南

时间轴工具栏末尾的 ⓘ 打开“自定义操作指南”。同一本地应用用户目录首次进入
自定义页面时自动展示；关闭后记录已查看，后续可随时重看。指南查看状态独立于
分析历史和自定义草稿，存储不可用时仍能关闭，并在本次运行内避免重复展示。
首次提示遇到其他模态弹窗时延后，重置确认关闭后也可补展示。

指南采用单页总览：真实页面截图与九个编号对应回合选择、预览、定位与边界、
增加/剃刀/删除、缩放、记分牌和比分红点、播放模式、撤销/重做/重置、导出。
点击编号滚动并聚焦对应说明，下方快捷键表按运行平台显示 macOS 或 Windows
组合键，并注明作用位置和工具模式。中英文内容与截图随应用语言切换。

截图由实际 Electron 中的 `CustomCutPage` 渲染并裁取工作区，包含五个演示片段、
未勾选回合、相邻分割片段、记分牌和比分红点。监视窗口的视频帧复用主页
“推荐视频拍摄视角”的球台人物线稿，截图不包含用户视频、侧栏或标题栏。
更新素材可执行 `node scripts/verify-custom-guide.mjs --capture`，其会写入中英文
PNG；正常验证执行 `node scripts/verify-custom-guide.mjs`，使用独立测试入口和用户目录。

打开指南暂停当前播放及等待中的播放意图，保持播放头、片段及播放模式；关闭后
继续暂停，由用户主动播放。打开时退出编辑工具、关闭多选及导出浮层。指南中
的空格和 Enter 可操作弹窗按钮，后台播放、A/D、撤销重做快捷键不会执行。
关闭按钮、“知道了”、Escape 或点击遮罩均可关闭，焦点回到 ⓘ；Tab 保持在弹窗内。

方向键需要区分焦点：播放头和片段边界手柄用左右键移动一帧，Shift 加速为
一秒；Home/End 仅将播放头定位到原片两端。记分牌获得焦点时方向键微调位置，
Shift 加大步幅。记分牌编辑框的 Enter 提交、Escape 取消，文本撤销仍归输入框处理。

## 剃刀与比分标记

时间轴工具按“增加 → 剃刀 → 删除 → 缩放”排列。剃刀与这些工具互斥；
开启后，鼠标悬停片段显示切割线，点击即可分成两个相邻片段。切割线在距离
播放头 8 像素以内吸附到播放头，以当前缩放后的屏幕距离计算。空白区、边界
以及任一侧不足一帧的位置不可分割。再次点击剃刀按钮、右键或 Escape 退出。
剃刀模式暂时关闭边界拖动和 A/D 边界快捷键，标尺、播放头与空格播放仍可用。

分割保留原片段所有画面与来源关系，不重新识别视频，也不自动删除回合间停顿。
两段分别按当前范围内的落点重算板数；旧记录没有落点时间时显示“—”。
分割清除两段的手动起始比分与胜方，后续比分依现有规则继承前序回合。
落刀不主动定位或播放；分割当前循环目标时，目标跟随播放头所在子段，
撤销后重做分割也遵守此规则。

有手动起始比分（包括显式 0:0）或胜方标注的片段，在时间轴片段内部左上角
显示小红点。自动继承的比分不产生红点，关闭记分牌也不会删除标注或红点。
分割清除标注后红点消失；撤销分割恢复标注与红点。此标记沿用现有标注操作。

## 撤销与重做

时间轴工具栏提供撤销、重做按钮。macOS 使用 ⌘Z 撤销、⌘⇧Z 重做；
Windows 使用 Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做。输入框与可编辑文本
保留自己的文本撤销，输入法组合输入期间不触发片段撤销。

片段分割、增删、边界调整、勾选以及片段起始比分和胜方编辑进入同一历史栈。
一次边界拖动算一步，未改变数据的操作不入栈；新编辑清空重做，最多保留
最近 100 步。撤销不恢复播放头时间、播放模式、记分牌位置或导出选项。
草稿自动保存当前状态，撤销栈仅保留于当前视频的编辑会话；取消导出或返回后
重新进入自定义保留该栈，切换视频、重新打开历史或重置改动时清空。

## 播放模式说明

时间轴下方的单个图标按钮依次切换“顺序播放 → 回合播放 → 循环播放 → 顺序播放”。三个图标分别是连续箭头、分开的箭头和环形箭头；按钮的中英文名称与悬停提示说明当前模式及下一模式。顺序播放沿用原片播放的完整时间轴行为。新草稿默认顺序播放；历史草稿保存并恢复模式，但不保存循环目标。

顺序播放沿原视频时间轴播放。回合播放依次播放视频轨上已勾选片段的当前起止范围，包括手动新增和调整后的片段，跳过间隔；最后一段结束时暂停，再次主动播放才从第一段重新开始。

- 播放中切入回合模式，在片段内部继续，在间隔中跳到下一段；已在所有片段之后则原地暂停。切回原片模式从当前位置继续。暂停时切换不移动播放头、不启动播放。
- 拖动播放头时可以自由查看任意位置。暂停时松开保留位置；播放时松开到空隙则进入下一段。暂停后再次播放也按当前位置进入回合。
- 点击列表中的未勾选回合会临时播放该回合，不改变选择或导出内容。结束后衔接时间上的下一段已选回合；若已进入某个已选片段则直接继续，没有后续片段则暂停在临时片段末尾。暂停后可以继续临时预览；点击别的回合、手动定位或切换模式会替换或结束临时预览。
- 勾选、取消、增加、删除和调整边界实时生效。暂停时不自动跳转；播放中当前范围失效则进入下一段。
- 视频轨完全为空时，顺序和回合模式都按原片播放，此规则优先于临时回合预览。所选模式仍保留，重新加入片段后按所选模式播放。

循环播放只循环一个回合片段的当前编辑范围，到片段末尾立即回到该段开头。进入模式或手动定位后，优先选播放头所在片段（可为未勾选片段）；落在间隔则选下一段已勾选片段，越过末段则选第一段。暂停时切换模式不移动播放头、不启动播放；再次播放才进入目标片段。点击回合列表或视频轨片段会切换目标并从其开头播放，点击未勾选片段也不会改变勾选或导出内容。

当前循环目标在列表中持续显示与定位提示一致的蓝色强调框，视频轨不额外标识。取消勾选不改变目标，边界调整立即生效；目标被删除后选下一段已勾选片段。视频轨为空且未指定目标时按原片播放，点击列表回合后开始循环。离开循环模式时清除目标；重新进入或从历史打开时按播放头位置重新选择。

这些模式仅控制监视窗口预览，不改变分析结果、片段选择或导出格式；模式本身随自定义草稿保存。跳转继续使用现有兼容预览链路，加载和代理准备期间以最后一次播放或暂停意图为准。

## 空格快捷键（PR #107 移植）

自定义页面的空格统一用于暂停/继续播放。焦点停在回合行、复选框、播放模式或其他按钮上时，空格不会重新播放该回合、修改勾选、切换模式或触发按钮。长按不连续切换，松开不触发原生点击；输入法组合输入期间不拦截空格。Enter 保留回合与按钮的原有激活行为。

本次仅移植 [PR #107](https://github.com/WeiyePlayer/TTcut/pull/107) 的快捷键及对应回归检查，保留 macOS 板数和多选卡片；不引入 Windows HEVC 预览、安装器注册改动。此规则取代早期验证中使用空格切换工具/播放模式的行为。

## 滚轮缩放工具

播放模式按钮前的放大镜按钮开启“缩放视频轨”。开启后，在时间轴标尺或片段轨道上向上滚动放大、向下滚动缩小，以鼠标位置为缩放中心；再次点击按钮或在自定义工作区右键可取消，恢复普通滚轮横向滚动。原有 Ctrl/⌘＋滚轮缩放入口继续可用。

缩放工具与增加、删除工具互斥，不改变播放模式。开启时仍可定位播放头、点击片段播放和调整片段边界，缩放只作用于时间轴。
