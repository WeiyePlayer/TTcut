### 时间基准

XML 是带前 2.5 秒/后 1 秒余量、相邻片段中点消重后的编辑区间，不是算法原始边界。
导出器当前即使标记 `ntsc=TRUE` 也用整数 timebase 写入 source in/out；因此本次按实际导出器
的整数 30 还原用户编辑，未用 30000/1001 引入额外漂移，也没有顺带修改导出器。
斜侧向保留原始 VFR 时间，不用平均帧率重建时间。局部视觉核对使用 FFmpeg 源时间抽帧；
OpenCV 的该 VFR 文件随机毫秒跳转截图与源时间不可靠，未作为验收证据。

## 原因与实现

1. 衰减死球规则会命中真实往返击球。保留 3 跳、间隔 <=1 秒、至少两项逐步下降 15%
   的定义；经用户授权加入严格击球保护：实际水平折返与相邻落点的反向水平速度共同成立才否决。
   单纯加速、垂直反弹、遮挡两端的坐标跳变都不算保护。后续独立击球不撤销已确认的死球前缀。
2. 旧往返判断依赖整个可见段长度，会漏掉长可见段内部的短快速飞行。新增局部实际观测判断：
   0.1–0.5 秒窗口、至少 4 点、相邻间隔 <=0.1 秒、位移 >=ROI 宽的 15%、速度 >=0.6 ROI宽/秒；
   至少 3 个分布式向前步骤，反向噪声路程 <=正向 15%。相反飞行间隔 <=0.5 秒且至少一个
   >=1 ROI宽/秒，才算往返；不会把单次跳到固定误检点当作飞行。
3. 稀疏垂直运动不应直接等同停顿。只在无静止证据、间隔 <=3 秒、有至少 3 段真实垂直运动时，
   允许累计支持比例从原有 15% 降到 12%；没有全局放宽缺帧合并。
4. 局部慢球不再触发整个候选否决。传球仍按局部移动段排除；本段附近有实际折返且扩展球台
   覆盖 >=50% 时保留慢球。其他独立传球证据继续保留，0 板整回合删除规则不变。
5. 持球/衣物误检的长水平漂移不再延长尾部：只针对 >=1 秒、无达标活动窗口、
   纵向范围 <=ROI 高 2%、横向范围 >=ROI 宽 5% 的段。它是运动边界提示，不能伪称死球或传球证据。

以上候选增强只由融合模式显式启用，旧连续模式保留原默认行为。
新结果仍为 schema v3，算法 provenance 升到 v2，包含候选/传球/击球保护版本及阈值；
旧 provenance v1 严格兼容，不重算或重新标记历史。

## 明确保留的未解决项

- 横向约 68.6–82.0 秒、93.1–106.4 秒仍有 XML 拆成两段而算法连在一起的情况。
  直接放宽弱运动再入场切分曾影响其他正常边界，未保留该方案。
- 1-193 约 394.3–395.8 秒的短传球仍可能保留，观察位移不足现有正向传球阈值。
  未仅为删除它全局降低传球位移阈值。
- 斜侧向约 630–634 秒仍有慢球被当成局部传球而切分的情况；约 435–449 秒尾段虽缩短，
  尚未达到 XML 的 447.733 秒编辑末尾。
- 新恢复的横向回合和部分补全末尾仍含与人工切点不同的准备/收球余量，不能声称逐帧边界完美。
- 这三段视频是开发/回归样本，不是独立测试集；未给出泛化准确率或声称所有传球/死球已去除。
