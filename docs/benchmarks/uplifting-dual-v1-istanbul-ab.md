# Istanbul 视频球模型 A/B 报告

本报告只记录无标注视频上的客观差异。由于没有人工真值，任何可见点、反弹帧或回合数量差异都不能用于断言哪套模型更准确。

## 测试条件

- 视频：`Maharu Yoshimura vs Andrej Gacina - MS Final - WTT Feeder Istanbul 2026.mp4`
- 编码与尺寸：H.264，1920×1080，60 FPS，20,131 帧
- 固定标定生成的 ROI：`(487, 238)–(1307, 707)`，即 820×469
- 两个档位分别在独立进程、同一 CUDA 设备、批量 2 下运行
- TrackNet 继续使用 1.25× 策略，实际输入为 280×160
- Uplifting 主模型不使用 1.25×，实际输入为 412×236；辅模型为 328×192

## 性能结果

| 指标 | `tracknet_v1` | `uplifting_dual_v1` |
| --- | ---: | ---: |
| checkpoint 加载 | 0.239 s | 0.461 s |
| 纯模型前向 | 24.817 s | 616.736 s |
| 解码、预处理和推理管线 | 82.962 s | 698.320 s |
| 完整分析（加载、预测、反弹、回合分组） | 83.312 s | 699.329 s |
| 管线平均 FPS | 242.653 | 28.828 |
| 峰值 CUDA 已分配显存 | 259,026,944 B | 357,500,928 B |

`complete_analysis_seconds` 从模型加载前开始，在反弹检测和三秒间隔回合分组完成后结束。文件哈希、环境信息收集和 JSON 序列化不计入该分析时间。
