# TTcut v1.2.0-beta.1

**简体中文** | [English](release-notes-v1.2.0-beta.1.en.md)

`v1.2.0-beta.1` 是 TTcut 1.2 功能线的首个测试版，新增可选的 Uplifting 双球识别模型，同时保留默认 TrackNet 档位和现有分析行为。

## 新球识别档位

- 设置页新增两个全局档位：“默认模型”继续使用 TrackNet；“新模型”使用 SegFormer++ B2 主模型和 WASB 辅模型的一致性过滤。
- 默认仍为 TrackNet。升级不会自动改变已有设置，也不会自动下载新模型。
- 新模型仅在 CUDA 分析组件可用时允许选择；CPU 用户可以看到说明，但不能触发下载或分析。
- 首次选择新模型时下载两个固定权重，共 105,177,076 字节。应用逐文件校验大小和 SHA-256，两个文件全部通过后才原子安装并保存选择。
- 新模型组件丢失、损坏或 CUDA 不可用时会阻止分析并引导修复，不会静默回退到 TrackNet。

## 动态 ROI 与识别结果

- 两个档位共享现有标定产生的动态 ROI。TrackNet 保持 1.25× 采样；新模型不使用 1.25× 过采样。
- 新模型根据解码后的实际分辨率和 ROI 尺寸自动计算输入：主模型使用 1/2 宽高并对齐到 4 像素，辅模型使用 2/5 宽高并对齐到 8 像素。
- 主辅坐标映射回源视频后按 1920×1080 标准化的 20 像素阈值过滤，接受时采用主模型坐标。
- 修复 ROI 后的重复 BGR→RGB 转换，使输入色彩条件与原 Uplifting 推理一致；同时加入热图亚像素定位、短缺失轨迹补全和反弹平台消歧。
- 新档位继续使用现有反弹检测、3 秒间隔回合分组和 `bounce_count`。界面中的板数仍表示落台反弹数，不表示球拍触球次数。
- 单视频、多任务和历史记录都会保存实际模型档位、ROI 及主辅输入尺寸。

## 模型下载

模型不写入 Git 仓库，也不内置在安装包中。应用从固定的 [dual-ball-models-1.0.0 运行时资产 Release](https://github.com/WeiyePlayer/TTcut-runtime-assets/releases/tag/dual-ball-models-1.0.0) 按需下载：

- `ttcut-ball-main-segformerpp-b2-1.0.0.pt`：99,091,962 字节；SHA-256 `f2e8b1050866a8bba540f731b379ee510a792f1af91996cb3bbc9cc0953f096e`。
- `ttcut-ball-aux-wasb-1.0.0.pt`：6,085,114 字节；SHA-256 `73bfe091d22dcca40f2ab19671370bb0f4236b451041dcbe72e8feefdb8539a0`。

组件下载支持重试、续传、逐文件哈希校验和双文件原子安装，也可从设置页手动导入这两个原始权重。

## Beta 更新通道

- 本 Release 标记为 GitHub Pre-release，并只发布 `beta.yml`。当前 `v1.1.4` 等稳定版安装不会收到这次自动更新。
- 安装本 Beta 后，更新器允许预发布版本，因此会继续接收后续 Beta；当更新的正式版发布时，也会回退到正式版的 `latest.yml` 并参与升级。
- 安装包继续使用固定 `CN=weiye` Authenticode 证书、RFC 3161 时间戳和签名更新清单校验。

## 验证

- 确定性 Worker 集成测试覆盖档位路由、动态 ROI、主辅输入尺寸、一致性过滤、源坐标回写、反弹检测及回合输出。
- 真实权重 CUDA 冒烟验证覆盖严格加载以及主 960×540、辅 768×432 输入。
- Istanbul 测试视频的最终新模型运行处理 20,131 帧，第三回合得到 6 个反弹；源视频分析前后大小和 SHA-256 未变化。
- 该视频没有人工标注；A/B 仅记录客观差异，不据此宣称任何模型的准确率。

完整 A/B 条件和结果见 [Istanbul 视频球模型 A/B 报告](benchmarks/uplifting-dual-v1-istanbul-ab.md)。
