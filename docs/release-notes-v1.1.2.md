# TTcut v1.1.2

## 自动更新修复

- 新增由发布私钥签署的更新清单，固定版本、渠道、安装包文件名、大小和 SHA-512。
- 应用内固定发布证书公钥；自签名证书仅出现 `UntrustedRoot` 时，仍会结合清单签名、安装包哈希、证书指纹和 RFC 3161 时间戳完成验证。
- 安装包、清单、签名或发布者任一不匹配都会拒绝更新。
- 设置页不再显示整段证书诊断 JSON，改为简洁提示和“手动下载更新”按钮；完整诊断仍保留在日志中。

## 从旧版本升级

v1.1.0 和 v1.1.1 的旧更新器会在运行新代码前拒绝自签名安装包，因此无法通过自动更新进入本版本。请从官方 Release 页面手动运行 `TTcut-1.1.2-x64-Setup.exe` 一次。安装路径、组件目录和用户数据继续沿用现有安装。

从 v1.1.2 开始，后续带有有效签名更新清单的版本可以恢复自动更新。

## 发布资产

正式 Release 必须同时包含 Setup、blockmap、`latest.yml`、`update-manifest.json`、`update-manifest.json.sig`、`SHA256SUMS.txt` 和 SBOM。缺少任一签名更新资产时不得发布。
