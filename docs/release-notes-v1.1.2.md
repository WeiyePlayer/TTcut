# TTcut v1.1.2

**简体中文** | [English](release-notes-v1.1.2.en.md)

`v1.1.2` 是 TTcut 1.1 功能线的正式补丁版本，集中修复自签名安装包的自动更新信任链，并完善 MOV、竖屏视频和导出完成后的支持提示。

## 自动更新与发布验证

- 新增由发布私钥签署的更新清单，固定版本、渠道、安装包文件名、大小和 SHA-512。
- 应用内固定发布证书公钥；自签名证书仅出现 `UntrustedRoot` 时，仍会结合清单签名、安装包哈希、证书指纹和 RFC 3161 时间戳完成验证。
- 安装包、清单、签名或发布者任一不匹配都会拒绝更新。
- 设置页不再显示整段证书诊断 JSON，改为简洁提示和“手动下载更新”按钮；完整诊断仍保留在日志中。

## MOV 与竖屏视频

- 单视频和批量任务现在都接受 MP4 与 MOV 文件，MOV 源视频统一导出为 MP4。
- 探测、自动/手动标定和导出会识别视频旋转元数据；手动标定继续使用源像素坐标，避免竖屏画面旋转后坐标错位。
- 标定、回合预览、导出预览和历史封面统一使用完整包含布局，竖屏画面不再被横向容器裁切。
- 需要重编码的旋转视频会归一化像素方向，并校验最终输出的分辨率、方向和旋转信息。

## 导出后的支持提示

- 单视频导出完成，以及已启动的批量队列处理完当前全部可执行项目后，会显示非阻塞的使用与赞助提示。
- 提示在应用内切换页面时保持显示，可直接前往赞助、关闭，或选择“30 天内不再显示”。
- 30 天抑制期限只保存在本机；存储不可用时不会影响导出或关闭提示。

## 从旧版本升级

`v1.1.0` 和 `v1.1.1` 的旧更新器会在运行新代码前拒绝自签名安装包，因此无法通过自动更新进入本版本。请从官方 Release 页面手动运行 `TTcut-1.1.2-x64-Setup.exe` 一次。安装路径、组件目录和用户数据继续沿用现有安装。

从 `v1.1.2` 开始，后续带有有效签名更新清单的版本可以恢复自动更新。

## 发布资产与验证

正式 Release 必须同时包含 Setup、blockmap、`latest.yml`、`update-manifest.json`、`update-manifest.json.sig`、`SHA256SUMS.txt` 和 SBOM。缺少任一签名更新资产时不得发布。

正式构建会验证内置模型、最小 Worker、应用与安装器结构、清单签名、安装包 SHA-512，以及 TTcut 主程序、卸载器和外层 Setup 的 Authenticode 签名与 RFC 3161 时间戳。
