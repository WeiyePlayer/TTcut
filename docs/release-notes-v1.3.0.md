# TTcut v1.3.0

**简体中文** | [English](release-notes-v1.3.0.en.md)

`v1.3.0` 是 TTcut 的正式版本，提供 Windows x64 与 macOS 15+ Apple Silicon 两个平台的桌面安装包。Windows 版本完善了连续运动模式和自动标定；macOS 版本首次提供基于原生 Core ML 的本地分析与媒体处理能力。

## Windows：连续运动模式

- “连续运动”现为默认回合识别方式，仍可在设置中切换为“落台判定”。
- 改进短回合、纵向运动和稀疏轨迹的连续性判断，减少有效回合被过早截断或过滤的情况。
- 加强对回合间慢速传球、停顿、等待和捡球片段的识别与分割，回合边界继续来自实际可见轨迹。
- “精彩回合”在连续运动模式下按时长档位筛选；历史记录和自定义时间轴继续依据每条分析结果实际使用的识别方式显示信息。

## Windows：自动标定

- 自动标定从视频中的 11 个时间点采样球桌候选，降低单个画面遮挡或背景干扰对结果的影响。
- 使用跨时间点稳定候选聚类和球桌几何一致性筛选标定结果，只有满足几何支持条件的结果才会通过。
- 手动标定支持按任意顺序标记四个球桌角点，完成后会显示连线并允许直接拖动微调。

## macOS 首个桌面版本

- 使用与 Windows 一致的 Electron 界面，并以内置的原生 Core ML Worker 在本机完成球桌、乒乓球分析和媒体处理。
- 当前 macOS 界面提供“落台判定”和“连续运动”选项，但原生 Worker 尚未接通连续运动算法；无论选择哪一项，当前分析结果均按“落台判定”生成。
- 当前 macOS 自动标定使用 5 个视频时间点；手动标定同样支持按任意顺序标记和拖动四个角点。

## 平台与安装包

- **Windows x64 · v1.3.0**：提供完整安装包和在线安装包。在线安装包会在安装阶段下载并校验必需运行资源，需要保持联网；完整安装包适合希望一次完成安装的场景。
- **macOS 15+ · Apple Silicon · v1.3.0**：提供 DMG（推荐）和 ZIP，已内置原生 Core ML 分析及媒体处理运行资源，不支持 Intel Mac。
- Windows 安装包继续使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单。未信任该证书的 Windows 环境仍可能显示“未知发布者”或 SmartScreen 提示。
- macOS 安装包使用临时签名且未经过 Apple 公证；首次打开若被系统拦截，请在“系统设置 > 隐私与安全性”中确认允许。当前 macOS 版本不提供自动更新。

## 范围说明

- 连续运动模式在已核对样本上完成了回归验证，但这些样本不构成所有拍摄角度、画质和场景下的统一准确率承诺。
- 自动标定仍可能受到严重遮挡、背景中的相似球桌、画面模糊或视频无法稳定定位时间点等因素影响；失败时可改用手动标定。
- 两个平台使用不同的分析运行时；Windows 的算法回归结果不能直接作为 macOS 算法效果证明。

## 验证

- TypeScript 类型检查通过；Vitest 47 个文件、270 项测试通过，3 个文件和 17 项测试按条件跳过。
- Python Worker 120 项测试通过；官网生产构建和 2 项渲染测试通过。
- 真实 Electron E2E 10 项通过、1 项按条件跳过，覆盖默认连续运动分析、自动标定、任意顺序手动标定、批量失败恢复、导出与预览。
- 完整安装包与在线安装包均已通过固定证书签名、更新清单签名、安装结构和运行资源交付边界校验。
- macOS 专用 Vitest 16 项与原生 Swift 22 项测试通过；应用已完成 Apple Silicon 包结构、运行资源、代码签名及 DMG 挂载校验。macOS 的验证不代表 Apple 公证或 Intel Mac 兼容性。
