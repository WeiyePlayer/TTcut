# TTcut v1.1.0

**简体中文** | [English](release-notes-v1.1.0.en.md)

`v1.1.0` 是 TTcut 1.1 功能线的首个正式版本，基于 `v1.1.0-beta` 完成分析性能、自动标定、导出稳定性和安装升级体验的收尾。

## 主要功能

- 单视频分析默认自动识别球桌；自动标定失败时可切换为手动四点标定。
- 新增批量任务，可一次选择多个 MP4 视频并串行执行自动标定、分析和导出；单项失败不会中断后续任务。
- 安装包内置回合分析与球桌识别双模型，打包前执行固定大小和 SHA-256 校验。
- 历史记录保存分析结果、完成类型和输出路径，并兼容旧版本记录。
- 新增应用内更新检查、后台下载和重启安装入口。
- 新增可选 `libx264` 组件；必须重编码时优先使用有效 x264，缺失或校验失败时回退 OpenH264。

## 正式版改进

- 根据每个视频的球桌标定生成固定分析 ROI，只裁切 TrackNet 输入；轨迹、回合时间和导出继续使用原视频坐标系。
- ROI 模型输入采用默认 1.25× 档位并向上对齐到 8 像素步长，在保留更多检测信息的同时减少无关画面计算。
- CUDA 分析改为有界流水线，收紧帧缓存和阶段等待；进度显示覆盖自动标定、模型加载、视频分析和结果整理。
- 自动标定采用元数据驱动的采样定位，降低长视频随机抽帧的重复解码开销，并保留多帧一致性校验。
- 修复分段导出中的 AAC 时间戳处理，增强流复制、合并和最终时长校验的一致性。
- 移除分析期间面向测试的中间弹窗，失败继续通过结构化错误和恢复入口呈现。

## 安装与升级

- Windows x64 安装包改用带向导的 NSIS：可选择安装根目录和桌面快捷方式，开始菜单快捷方式始终创建。
- 程序文件写入 `<root>\app`，大型运行时和组件写入 `<root>\data\components`，升级时保留组件数据。
- 安装器可识别并迁移旧版安装布局；应用内更新切换到稳定版 `latest` 通道。
- 下载 `TTcut-1.1.0-x64-Setup.exe`，并使用 Release 附带的 `SHA256SUMS.txt` 核对完整性。

## 发布验证

- TypeScript 类型检查、Vitest 和 Worker Python 测试通过。
- 发布构建验证内置模型、最小 Worker、Renderer 隔离、Electron Fuse、NSIS 更新元数据和发布资产结构。
- 正式资产验证 TTcut 主程序、卸载程序和外层安装器的 Authenticode 签名与时间戳。

TTcut 不上传视频、分析结果或历史记录。内置模型可离线使用；首次安装 Python/PyTorch 分析运行时和 FFmpeg 视频处理组件仍需要联网。
