# TTcut Windows v1.3.12

**简体中文** | [English](https://github.com/WeiyePlayer/TTcut/blob/develop/docs/release-notes-v1.3.12.en.md)

## 更新内容

- 将标定预览逐帧回退提交 `396d830` 移植到 Windows develop：浏览器视频解码不可用时，自动使用 FFmpeg 提取所选时间的画面，继续选择标定帧和标注球桌。
- 提取画面遵循视频显示旋转，HDR 素材采用预览色调映射，并限制预览尺寸；仅改变预览，不替换原视频。
- 快速拖动时优先处理最新帧请求，过期结果不覆盖当前画面；画面未就绪时不允许误标定，提取失败有明确提示。
- 新增受限的帧提取 IPC 和图片媒体通道，沿用源文件访问控制及退出清理。保留 Windows 原生预览接口及兼容预览停用行为。
- 不改变 BlurBall 模型、分析采样默认值、回合识别或导出规则。

## 交付与限制

- Windows x64 完整安装包：`TTcut-1.3.12-x64-Setup.exe`，包含模型、运行时、原生预览与视频工具。沿用固定 `CN=weiye` 自签名证书和时间戳，系统仍可能提示 SmartScreen 或未知发布者。
- 按本次要求，不运行单元测试、类型检查、真实视频/界面验收或额外验证；正式打包流程自身的内置检查仍保留。不据此声称功能已验收。
- 仅准备 Release 草稿，暂不公开发布；不提供新的 macOS 安装包。
- 公开发布前仍需核对并补齐原生预览/libmpv 固定构建及其链接依赖的对应源码与许可材料。
