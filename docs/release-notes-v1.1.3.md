# TTcut v1.1.3

**简体中文** | [English](release-notes-v1.1.3.en.md)

`v1.1.3` 是 TTcut 1.1 功能线的正式补丁版本，重点减少短时间重复弹跳候选造成的回合板数虚高，并提高复杂 MP4 流布局的解码兼容性。

## 回合与板数识别

- 默认最小弹跳间隔从 0.12 秒调整为 0.315 秒，过滤球网接触等情况可能产生的短时间重复候选。
- 去重始终与上一个已保留弹跳比较；被忽略的候选不会移动基准，因此后续满足间隔条件的真实候选仍可保留。
- 间隔恰好为 0.315 秒的候选会保留，仅丢弃严格小于阈值的候选，并加入边界与非传递场景回归测试。
- 已保存的历史分析结果不会自动迁移；新分析和用户主动重新分析会使用新规则。

TTcut 显示的“板数”仍是依据球在桌面区域的弹跳事件计算的代理值，并不等同于逐次识别球拍击球。本次优化针对已确认的重复弹跳候选与计数虚高问题，不代表所有拍摄条件下都能获得真实击球次数。

## 复杂视频与运行环境兼容

- 分析和自动标定 Worker 会固定提高 OpenCV FFmpeg 的数据包读取尝试上限，避免 GoPro HEVC 视频中的音频、时间码、遥测和描述流过早耗尽默认预算。
- 对包含大量辅助流的 MP4，分析不再因只读取少量视频帧就结束而误报“未识别到有效回合”。
- 解码帧数明显低于视频元数据帧数时，会返回明确的视频解码错误，便于区分媒体兼容问题与确实没有有效回合。
- 这一改动提高的是复杂视频流和 Worker 进程环境的兼容性，不扩大 Windows x64 之外的官方系统支持范围。

## 从旧版本升级

`v1.1.2` 用户可以通过应用内更新升级到本版本；更新器会验证签名更新清单、安装包摘要、固定发布证书和 RFC 3161 时间戳。

`v1.1.0` 和 `v1.1.1` 的旧更新器仍无法接受自签名安装包，请从官方 Release 页面手动运行 `TTcut-1.1.3-x64-Setup.exe`。现有安装路径、组件目录和用户数据继续沿用。

## 发布验证

- 完整 TypeScript、Vitest 和 Worker 回归测试覆盖新的运行环境、解码完成度及 0.315 秒去重边界。
- 真实 CUDA 视频分析验证复杂 GoPro 文件可以完整读取，并验证保留弹跳之间不存在小于 0.315 秒的间隔。
- 正式 Release 包含 Setup、blockmap、`latest.yml`、`update-manifest.json`、`update-manifest.json.sig`、`SHA256SUMS.txt` 和 SBOM。
