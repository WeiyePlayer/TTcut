# TTcut v1.3.3

**简体中文** | [English](https://github.com/WeiyePlayer/TTcut/blob/v1.3.3/docs/release-notes-v1.3.3.en.md)

`v1.3.3` 是面向 Windows x64 与 macOS 15+ Apple Silicon 的正式版本更新。本次新增多视频回合合并导出，优化 Windows 回合识别策略，并修复了已确认的问题。

## 新功能

- 多任务剪辑新增“合并为一个视频”：可为不同视频分别选择“所有回合”或“精彩回合”，再按任务顺序剪辑并合并为一个 MP4 成片。
- 合并导出会统一不同来源视频的画面尺寸、方向、帧率、色彩格式和音频轨道，并在完成前解码校验整个输出。
- 合并失败或取消时会保留已经完成的分析结果，可直接重试，无需重新分析。

## Windows 回合识别优化

- Windows 默认回合识别升级为融合运动轨迹与落点证据的策略，同时保留连续运动和落台判定选项。macOS 继续使用原生 Core ML 连续运动识别，不把 Windows 混合策略误标为 macOS 能力。
- 优化慢速回球、短距离反向回球、回合尾段和离桌传球的判断，减少有效回合被错误拆分、提前截断或漏检的情况。
- 在本次有人工反馈和冻结轨迹的真实样本中，修正了两组错误拆分、一个回合尾段截断和一个漏检回合；该准确性结论只覆盖已验证样本，不代表所有拍摄角度、编码和比赛场景。

## 问题修复

- 改善部分原视频无法直接播放时的兼容预览与分析诊断。
- 修复可变帧率视频规范化后处理元数据仍可能引用原始媒体路径的问题。
- 修复合并任务完成分析后列表列宽发生变化的问题。

## 安装包

- **Windows x64 · v1.3.3**：`TTcut-1.3.3-x64-Setup.exe`，提供包含必需运行资源的完整安装包，可一次完成安装。安装包使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单；未信任该证书的环境仍可能显示“未知发布者”或 SmartScreen 提示。
- **macOS 15+ · Apple Silicon · v1.3.3**：`TTcut-1.3.3-arm64-Setup.dmg`（推荐）与 `TTcut-1.3.3-arm64-Setup.zip`，内置原生 Core ML 分析及媒体处理运行资源，不支持 Intel Mac。
- macOS 安装包使用临时签名且未经过 Apple 公证；首次打开若被系统拦截，请在“系统设置 > 隐私与安全性”中确认允许。当前不提供软件内更新。

## 验证

- Windows 发布验证：TypeScript 类型检查通过；Vitest 共 54 个测试文件、316 项测试通过，另有 4 个文件、21 项测试按既有条件跳过；Python 共 185 项回归测试通过。
- 官网生产构建及 2 项渲染测试通过。
- 多视频合并通过 4 项真实 FFmpeg 混合媒体回归，覆盖不同尺寸、方向、帧率、可变帧率及有无音轨的输入；打包态 Electron 合并、历史读取和预览流程通过。
- Windows 完整安装包通过固定证书签名、更新清单签名、安装结构和运行资源交付边界校验。
- macOS 通过 TypeScript、专用 Vitest、原生 Swift、正式 Electron 流程、批量界面、arm64 包体签名及 DMG/ZIP 交付校验。
