# TTcut v1.1.4

**简体中文** | [English](release-notes-v1.1.4.en.md)

`v1.1.4` 是 TTcut 1.1 功能线的正式补丁版本，修复视频处理组件下载链接失效的问题。

## 视频处理组件下载修复

- “视频处理组件”使用的标准 FFmpeg 下载地址已切换到 TTcut 运行时资产仓库中的固定 Release。
- 可选 x264 编码组件的下载地址同步修复，首次安装或重新安装时不再访问已经失效的上游固定链接。
- 新地址提供的仍是原先验证过的归档；文件名、文件大小、SHA-256、FFmpeg 版本、归档根目录和安装路径均保持不变。
- 新地址支持组件下载器需要的 HTTPS Range 请求，便于执行分段读取和续传。

## 用户影响

- 尚未安装视频处理组件的用户，在更新到 `v1.1.4` 后可以重新执行组件安装。
- 已经安装完成的标准 FFmpeg 或可选 x264 组件不会被替换，也不需要重新下载。
- 本版本不修改视频分析、回合识别、动态 ROI、板数计算或视频导出逻辑。

## 从旧版本升级

`v1.1.2` 和 `v1.1.3` 用户可以通过应用内更新升级到本版本；更新器会验证签名更新清单、安装包摘要、固定发布证书和 RFC 3161 时间戳。

`v1.1.0` 和 `v1.1.1` 的旧更新器仍无法接受自签名安装包，请从官方 Release 页面手动运行 `TTcut-1.1.4-x64-Setup.exe`。现有安装路径、组件目录和用户数据继续沿用。

## 发布验证

- 两个 FFmpeg 资产的服务器端文件大小和 SHA-256 均与组件目录中的固定值一致。
- 全部组件下载地址通过 HTTPS Range 网络验证，两个修复后的地址均返回 HTTP 206 和正确的总文件大小。
- 正式 Release 包含 Setup、blockmap、`latest.yml`、`update-manifest.json`、`update-manifest.json.sig`、`SHA256SUMS.txt` 和 SBOM。
