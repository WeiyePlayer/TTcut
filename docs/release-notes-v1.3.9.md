# TTcut Windows v1.3.9

**简体中文** | [English](https://github.com/WeiyePlayer/TTcut/blob/develop/docs/release-notes-v1.3.9.en.md)

`v1.3.9` 是面向 Windows x64 的正式版本更新，新增比分牌样式、剃刀分割、撤销重做和自定义操作指南。

## 比分牌

- 新增经典蓝、橙、绿横条及红蓝双牌四种样式，在设置中可视化选择并保存；旧数据保留经典蓝色样式。
- 原生视频预览、比分牌图片与导出视频使用一致的样式和尺寸，并改进旋转视频的显示尺寸适配。
- 补齐视频开头、回合间隙和结束后的比分编辑；开始编辑时暂停播放，回合间隙不允许标注胜方。
- 时间轴中的小红点标明手动起始比分或胜方，自动继承的比分不显示红点。

## 剪辑与操作指南

- 新增剃刀工具，将片段分割为相邻两段。切割线可吸附播放头，并限制分割后的两侧至少各有一帧。
- 分割保留视频范围和来源关系，按片段内落点重新计算板数；旧记录缺少落点时间时显示“—”。分割会清除两段的手动起始比分与胜方标注。
- 新增最多 100 步撤销重做，覆盖分割、增删、边界、勾选及比分和胜方编辑。Windows 支持 Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z，原生预览获得焦点时同样可用。
- 分割后的片段可保存至草稿、重新打开及独立导出；当前循环目标随分割后播放头所在片段调整。
- 新增中英文自定义操作指南，首次进入自动展示，工具栏可随时重看。打开时暂停播放并让原生视频窗口避让；关闭后保持暂停。

## 发布文件

- **Windows x64 完整安装包**：`TTcut-1.3.9-x64-Setup.exe`，包含分析模型、运行时、原生预览与视频处理工具。
- 安装包采用固定 `CN=weiye` 自签名 Authenticode 证书和 RFC 3161 时间戳。尚未信任该证书的 Windows 系统仍可能提示“未知发布者”或 SmartScreen。
- GitHub Release 保持草稿状态，暂不公开发布；本次不提供新的 macOS 安装包。

## 公开发布前待办

- 原生预览依赖的随包 NOTICE 要求提供固定构建及其链接依赖的对应源码与许可材料。公开发布前需核对并补齐这些分发材料；本次草稿仅附安装包与更新校验文件。
