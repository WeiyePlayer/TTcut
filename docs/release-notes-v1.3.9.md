# TTcut v1.3.9

**简体中文** | [English](https://github.com/WeiyePlayer/TTcut/blob/macos/docs/release-notes-v1.3.9.en.md)

面向 Windows x64 和 macOS 15+ Apple Silicon，新增比分牌样式、剃刀分割、撤销重做和自定义操作指南。

## 双平台更新

- 比分牌新增经典蓝、橙、绿横条及红蓝双牌四种样式，可在设置中预览、选择和保存；旧数据默认保留经典蓝。预览、比分牌图片与导出采用一致样式，并改善旋转视频尺寸适配。
- 支持视频开头、回合间隙和末尾编辑比分；开始编辑时暂停播放，间隙不允许标注胜方。时间轴红点仅标明手动起始比分或胜方。
- 新增剃刀工具，将片段分为相邻两段，切割线可吸附播放头，两侧至少各保留一帧。保留来源关系，依据落点重新计算板数；缺少落点时间的旧记录显示“—”。分割清除两段的手动起始比分及胜方。
- 最多 100 步撤销重做，覆盖分割、增删、边界、勾选和比分编辑。Windows 使用 Ctrl+Z、Ctrl+Y 或 Ctrl+Shift+Z；macOS 使用 Cmd+Z、Cmd+Shift+Z。
- 分割片段支持草稿保存、重开及独立导出；循环目标随分割后播放头所在片段调整。
- 新增中英文操作指南，首次进入自动展示，工具栏可随时重看。打开时暂停播放，关闭后保持暂停。

## 平台与安装包

- **Windows x64 v1.3.9**：`TTcut-1.3.9-x64-Setup.exe`，包含模型、运行时、原生预览及视频工具。使用固定 `CN=weiye` 自签名 Authenticode 证书与 RFC 3161 时间戳，未信任证书的系统可能提示未知发布者或 SmartScreen。
- **macOS 15+ Apple Silicon v1.3.9**：`TTcut-1.3.9-arm64-Setup.dmg`（推荐）及 `TTcut-1.3.9-arm64-Setup.zip`，不支持 Intel Mac。保留原生 Core ML 分析、兼容预览及 Swift 原生比分牌导出。
- macOS 为临时签名、未公证；首次打开受阻时可在系统设置的隐私与安全性中允许。软件内更新禁用，不提供 `latest-mac.yml`。
