## 原因与实现范围

- 斜侧向：较慢、高弧线且离桌的有效来回球被传球过滤器切开。仅在有真实击球反向证据、紧随的相反方向连续飞行时保护，不按固定时间窗强制合并。
- Maharu 第 32 回合：有效触球的水平速度略低于原死球保护阈值，导致有效尾段被当成衰减死球。保留真实击球和落点两侧相反速度条件，局部降低其速度门槛。
- Maharu 漏检：短反向回球不足 ROI 宽度的 15%，强飞行筛选只剩同方向球路，整段被拒绝。混合模式在紧邻强飞行后存在分布式短反向轨迹时保留；连续可见模式维持原有分支。
- 轨迹保护仍要求最少点数、实际连续时间、净位移、速度、多步移动以及小幅回退。跳点、时间空洞与单次跳跃不作为反向回球证据。
- 算法来源字段升级为 v3，候选细化 v2、传球过滤 v3、死球保护 v2；客户端同时兼容旧 v1/v2 历史。
