# TTcut v1.1.0-beta

这是 `1.1.0` 功能线的 Beta 版本，集中加入自动球桌标定、批量分析、内置双模型、自动更新和可选 x264 编码能力。

## 主要更新

- 单视频分析默认使用自动标定，可切换为手动四点标定；自动识别结果会经过多帧一致性校验。
- 新增批量任务工作流，可一次选择多个 MP4 视频，串行执行自动标定、分析和导出；单项失败不会阻断后续任务。
- 批量输出保存到对应源视频目录，并使用独立命名避免覆盖原视频和已有成片。
- 安装包内置 `analyze.pt` 和 `table_analyze.pt` 双模型，打包前执行固定大小与 SHA-256 校验；Python/PyTorch 运行时仍按需安装。
- 历史记录支持保存 0 回合分析、完成类型和输出路径，并兼容读取旧版本记录。
- 新增分阶段分析进度，区分自动标定、模型加载、视频分析和结果整理。
- 新增应用内自动更新检查、后台下载和重启安装入口。

## 编码与兼容性

- 新增可选 `libx264` 组件。有效 x264 会自动优先用于必须重编码的导出，参数为 `veryfast` 和 `CRF 18`。
- 保留 OpenH264 默认组件和原有下载行为；x264 缺失、损坏或校验失败时自动回退 OpenH264。
- 高于 4K 且必须重编码的任务会在启动 FFmpeg 前检查 x264，避免任务运行后才失败。
- 保留满足安全切点条件时的流复制路径，不会因为安装 x264 而强制重编码。
- 删除 Windows build 和系统版本硬拦截；Windows x64 仍是当前主要构建目标，实际能力由组件与任务自检确认。
- 修复组件导入校验、CUDA 13.2/RTX 50 系显卡运行时选择和导出时长容差相关问题。

## 安装与升级

下载 `TTcut-1.1.0-beta-x64-Setup.exe` 后安装，并使用 Release 附带的 `SHA256SUMS.txt` 核对文件完整性。

这是 GitHub Pre-release，不会替换 `v1.0.2` 的稳定版标记。安装包使用 `CN=weiye` 自签名 Authenticode 证书，Windows 仍可能显示“未知发布者”或 SmartScreen 提示。

TTcut 不上传视频、分析结果或历史记录。内置模型可离线使用；首次安装 Python/PyTorch 分析运行时和 FFmpeg 视频处理组件仍需要联网。
