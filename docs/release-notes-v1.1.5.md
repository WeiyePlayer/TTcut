# TTcut v1.1.5

**简体中文** | [English](release-notes-v1.1.5.en.md)

`v1.1.5` 是 TTcut 1.1 功能线的正式热修复版本，修复有效导出因时长校验过严而被误报失败的问题。

## 导出时长误判修复

- 导出完成后的生产校验重新使用既有的 2 秒领域容差，不再使用 `0.1 秒或 2 帧`中的较大值作为过严阈值。
- 实际输出时长与目标时长的偏差不超过 2 秒时视为有效；超过 2 秒的结果仍会返回 `EXPORT_DURATION_MISMATCH`。
- 这项修复主要覆盖 FFmpeg 分段剪辑、时间基调整或封装产生的正常小幅时长偏差。
- 文件可读性、最小文件大小、分辨率、编码、音频、A/V 同步、起始时间戳、旋转和元数据等其他导出校验保持不变。

## 用户影响

- 之前在剪辑结束后收到“导出时长不匹配”或导出失败提示的用户，可以在更新到 `v1.1.5` 后重新导出。
- 本版本只修复 `EXPORT_DURATION_MISMATCH` 误判，不代表组件缺失、磁盘空间不足、编码器错误或源视频损坏等其他导出失败原因已经改变。
- 本版本不包含 `v1.2.0-beta.1` 的双模型功能，也不修改视频分析、动态 ROI、回合或板数识别逻辑。

## 从旧版本升级

`v1.1.2`、`v1.1.3` 和 `v1.1.4` 用户可以通过应用内更新升级到本版本；更新器会验证签名更新清单、安装包摘要、固定发布证书和 RFC 3161 时间戳。

`v1.1.0` 和 `v1.1.1` 的旧更新器仍无法接受自签名安装包，请从官方 Release 页面手动运行 `TTcut-1.1.5-x64-Setup.exe`。现有安装路径、组件目录和用户数据继续沿用。

## 发布验证

- 导出校验回归测试覆盖 2 秒容差以内接受、超过容差拒绝的场景。
- OpenH264 与 x264 的真实分段导出集成测试覆盖视频、音频、时间戳及最终输出验证。
- 正式 Release 包含 Setup、blockmap、`latest.yml`、`update-manifest.json`、`update-manifest.json.sig`、`SHA256SUMS.txt` 和 SBOM。
