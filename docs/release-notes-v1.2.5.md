# TTcut v1.2.5

**简体中文** | [English](release-notes-v1.2.5.en.md)

`v1.2.5` 是 TTcut 1.2 功能线的正式版本，带来随安装包提供的 BlurBall 球识别模型，并修复批量任务结束时的任务状态竞争问题。

## BlurBall 默认模型

- 默认使用随安装包提供的 BlurBall 模型定位乒乓球，支持 CPU 和 CUDA；仍可在设置中切换 TrackNet。
- BlurBall、TrackNet 和球桌识别权重均随安装包提供，构建前按固定文件大小和 SHA-256 校验，安装后不需要另行下载模型权重。
- 移除旧的 B2/Uplifting 双模型下载和运行时路径。升级后，旧的未知模型配置会回退到当前支持的 BlurBall 模型。
- 本次模型切换不改变球桌自动标定、统一球台区域过滤、回合分组和剪辑导出边界规则。

## 批量任务稳定性

- 修复分析或导出完成时释放任务状态与发送终止事件的竞态，避免下一个排队任务错误收到 `TASK_BUSY`。
- 保持无限队列接纳和重任务串行执行；用户取消、失败和正常完成仍会分别返回对应终止状态。

## 继承的修复

- 保留 v1.2.4 的长视频 CPU 导出关键帧探测、取消传播和组件设置子进程修复。

## 影响范围

- 本版本变更了默认球识别模型和模型资源边界；不引入新的 UpliftingTableTennis/B2 权重，也不改变用户视频上传、账号或遥测行为。
- 安装包继续使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单；未信任该证书的 Windows 仍可能显示“未知发布者”或 SmartScreen 提示。

## 验证

- 完成 TypeScript 类型检查、串行 Vitest、Worker pytest、官网生产构建与渲染 HTML 测试。
- 完成正式 NSIS 构建，并核对安装包内的 BlurBall、TrackNet 和球桌识别权重大小及 SHA-256。
