# TTcut Windows v1.3.8

**简体中文** | [English](https://github.com/WeiyePlayer/TTcut/blob/develop/docs/release-notes-v1.3.8.en.md)

`v1.3.8` 是面向 Windows x64 的正式版本更新，重点改善自定义剪辑、比分牌导出、原片预览与分析稳定性。

## 自定义剪辑与比分牌

- 自定义编辑草稿随历史记录保存，重新打开时恢复片段选择、编辑边界、播放模式、比分牌及导出选项。
- 新增逐回合比分牌，支持编辑选手姓名和比分、调整位置与大小，并叠加到导出视频。选择回合得分方后自动进入下一回合。
- 新增循环播放模式，反复播放当前回合的编辑范围；回合列表持续突出显示循环目标，点击其他回合即可切换。循环预览不会改变导出选择。

## 预览与分析稳定性

- Windows 自定义剪辑新增原生视频预览，直接播放原视频，改善跳转、暂停与时间轴拖动的响应。
- 修复原生预览中的输入响应、离开后重新打开编辑器及播放头拖动定位问题。
- 复用已经验证的 DirectML 会话，减少重复初始化；分析期间遇到加速失败时尝试较小批量，必要时回退 CPU。
- 分析完成通知会等待任务资源清理结束，减少后续任务误报忙碌；历史写入按顺序处理，未完成任务不会覆盖上一次成功结果。

## 发布文件

- **Windows x64 完整安装包**：`TTcut-1.3.8-x64-Setup.exe`，包含分析模型、运行时、原生预览与视频处理工具。
- 安装包采用固定 `CN=weiye` 自签名 Authenticode 证书和 RFC 3161 时间戳。尚未信任该证书的 Windows 系统仍可能提示“未知发布者”或 SmartScreen。
- GitHub Release 保持草稿状态，暂不公开发布；本次不提供新的 macOS 安装包。

## 公开发布前待办

- 原生预览依赖的随包 NOTICE 要求提供固定构建及其链接依赖的对应源码与许可材料。当前草稿附件尚未包含完整对应源码包，需在公开发布前补齐。

## 验证

- TypeScript 类型检查通过；项目测试 510 项通过、25 项跳过，包含实际视频编码的比分牌导出集成测试；Python Worker 测试 259 项通过、3 项跳过。
- 本次打包的 Windows 程序通过 5 项真实原片预览检查及 8 项比分牌编辑检查，覆盖播放、暂停、重开、时间轴拖动、中文姓名、比分输入及滚轮调整。
- 正式安装包构建、模型与运行时完整性、原生预览文件哈希、Authenticode 签名及签名更新清单均通过自动校验。
- 未进行安装器人工安装或分析识别效果的真实视频对照；未验证 macOS 构建。
