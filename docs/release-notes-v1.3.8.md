# TTcut v1.3.8

**简体中文** | [English](https://github.com/WeiyePlayer/TTcut/blob/v1.3.8/docs/release-notes-v1.3.8.en.md)

面向 Windows x64 和 macOS 15+ Apple Silicon，新增编辑草稿保存、逐回合比分牌及循环播放。

## 两个平台的编辑功能

- 编辑草稿随历史记录保存，重新打开时恢复片段选择、编辑边界、播放模式、比分牌及导出选项。
- 比分牌支持中英文选手姓名、局分和小分、位置与大小调整，并叠加到合并或分段导出视频。选择回合得分方后自动进入下一回合。
- 循环播放当前回合的编辑范围，列表持续突出显示循环目标；点击其他回合可切换目标，导出选择保持独立。
- 历史写入串行处理，未完成任务不会覆盖上一次成功结果。

## Windows

- 原生预览直接播放原视频，改善跳转、暂停和时间轴拖动；修复输入响应及重开编辑器的问题。
- 复用已验证的 DirectML 会话；加速失败时尝试较小批量，必要时回退 CPU。分析完成通知等待任务资源清理结束。
- `TTcut-1.3.8-x64-Setup.exe`：完整安装包，包含模型、运行时、原生预览及视频工具。使用固定 `CN=weiye` 自签名证书与 RFC 3161 时间戳，未信任证书的系统可能提示未知发布者或 SmartScreen。

## macOS

- 保留 Core ML 原生分析、源时间排除区间及兼容预览，新增 Swift 原生比分牌导出，支持旋转视频、HDR10 和 HLG。
- 修复初始位置、回合间隙及末尾无法编辑比分的问题；显示与保存均对应明确的已选回合。双击字段时暂停播放，避免编辑过程中跨回合丢失焦点。
- `TTcut-1.3.8-arm64-Setup.dmg`（推荐）和 `TTcut-1.3.8-arm64-Setup.zip`：适用于 macOS 15+ Apple Silicon，不支持 Intel Mac。
- macOS 包为临时签名、未公证；首次打开受阻时可在系统设置的隐私与安全性中允许。软件内更新禁用，不提供 `latest-mac.yml`。

## 验证范围

- Windows 发布准备记录：类型检查通过，项目测试 510 通过、25 跳过，Python Worker 259 通过、3 跳过；原片预览 5 项和比分牌编辑 8 项通过，安装包签名与更新清单通过自动校验。
- macOS 的既有移植验收覆盖真实比分牌成片、循环解码、草稿重启恢复及批处理；本次发布另行检查最终安装包。
- 未进行 Windows 安装器人工安装或真实比赛分析准确率对照；签名完整性校验不等同于 Apple 公证。
