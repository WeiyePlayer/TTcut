# TTcut v1.2.10

**简体中文** | [English](release-notes-v1.2.10.en.md)

`v1.2.10` 是 TTcut 1.2 功能线的正式版本。它将可变帧率视频的固定帧率重编码改为可选项，并修复安装流程中的已知问题。

## 可变帧率视频处理

- 设置新增“重编码为固定帧率”选项，默认关闭。
- 关闭时，可变帧率视频直接使用原始媒体完成分析、预览、剪辑和新建 XML，不创建固定帧率缓存，也不会显示回退警告。
- 开启时，标定完成后会为可变帧率视频生成固定帧率处理媒体，再用于后续流程。这样可提高剪辑时间点的稳定性，但会增加处理时间和磁盘占用。
- 标定始终使用原始视频。开启后的固定帧率准备如遇空间不足、转码失败或输出校验失败，应用会显示原因并继续使用原始可变帧率视频；取消和退出不会静默回退。

## 问题修复

- 修复安装程序在部分环境中被预安装磁盘空间探测错误阻断的问题。

## 安装包

- Release 同时提供完整安装包和在线安装包。在线安装包会在安装阶段下载并校验必需运行资源，需要保持联网；完整安装包适合希望一次完成安装的场景。

## 范围说明

- 本版本不提供统一的量化准确率百分比。实际识别结果仍会受到视频画面、标定质量、选择的分析精度和本机环境影响。
- 安装包继续使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单。未信任该证书的 Windows 环境仍可能显示“未知发布者”或 SmartScreen 提示。

- `npm run typecheck` 通过；串行 Vitest：46 个文件通过、246 个测试通过，3 个文件和 17 个测试按条件跳过。
- Worker 测试：45 个通过；官网构建和渲染测试：2 个通过。
- 完整安装包和在线安装包均完成固定 `CN=weiye` 证书签名、更新清单签名、安装包结构与模型交付边界校验。
