# ADR 0014：连续运动主定位、落点筛除无效片段

## 状态

已接受。替代 ADR 0013 的新 BlurBall 模式选择；不迁移或重算历史分析。

## 决策

- 桌面随包 BlurBall 固定完整单阶段、置信阈值 0.30、`hybrid_motion_bounce`。
  request v5 只接受该组合；显式本地 TrackNet 仍用 v4/continuous_visibility。
  旧 request v1–v4 继续支持；设置中旧方式/精度字段读取忽略、下次保存移除。
- 连续运动候选复用既有迟滞、运动筛选、遮挡桥接和慢速传球证据。
  缺失落点不是边界；有连续轨迹并不否决明确无效证据。
- 死球簇至少 3 跳、间隔 <=1.0 秒。间隔、图像空间反弹高度、离开速度中至少两项，
  在该子序列所有比较中满足后值 <=0.85 × 前值；不可计算的指标不参与。
  扫描连续子序列并合并最大合格簇；删除第一跳至最后一跳，不使用落点位置、半区、
  球网规则。初版 v1 不设重新击球否决；2026-09-08 经用户授权，v2 增加严格击球保护：
  衰减簇内部存在真实观测支持的水平折返，且折返两侧落点的离开/接近水平速度反向，
  才否决该段死球判断。单纯速度增大、垂直反弹、缺帧间位移不算击球。
  后续击球不会撤销之前已经独立满足条件的死球前缀。
- 反弹高度是两次落点之间相对于端点连线的图像向上最大偏离，并非物理高度。
  离开速度用落点后最多五个源帧的逐步速率中值，时间单位秒；先取模再取中值，
  避免窗口覆盖反弹顶点时正反方向抵消。缺帧不补猜指标。
  15% 是用户确定的内部固定阈值，不是数据拟合结果，不提供 UI 或环境变量覆盖。
- 慢速传球保留既有机位限制、运动门槛和紧邻反向飞行的发球保护，按局部移动段
  保存证据；后续独立对打不否决已确认传球。只删除移动段，不扩到持球或停顿。
  v2 不再因为局部慢段否决整个候选；局部真实折返且扩展球台覆盖至少 50% 时保留该慢球。
- v2 候选细化保留连续段内部的短时往返飞行；至少四次真实观测、三个分布式移动步骤，
  相邻观测间隔 <=0.1 秒，避免把跳到静态误检点当成快速飞行。只在融合模式启用。
  无停顿、三段垂直运动支持时允许稀疏连续回合跨越短缺失；无有效运动的长水平漂移
  不再延长尾部。未改变旧连续模式的默认细化行为。
- 筛除区间为源时间半开区间；终点在最后被删帧之后。重叠区间规范化、证据合并。
  分割后右侧独立启动，回溯到首个真实可见帧；最终零板区间整体删除并记录原因。
- 新 result v3 保存正板数、有效落点时间、excluded_fragments 和阈值/筛选版本溯源。
  源时间保留精度以避免半开边界的四舍五入串位；普通页面不新增诊断区或自动 sidecar。
- Board Count 的现有定义及文案不变；精彩严格 >3/5/7，自定义板数只用有效事件。
  旧连续结果仍无板数、按原时长筛选；历史结果不重算。result schema v3 内的算法
  provenance v1/v2 分别严格校验，不能把旧结果改标为新版。
- 新原始间隔严格 <3 秒才合并，取消固定一秒尾部，仅应用用户余量。
  历史保留 <5 秒及各自原尾部规则。导出余量允许重新包含已排除画面。

## 取舍与验收

零板真回合仍会被删除；真实击球观测不足时，满足衰减模式的真对打仍可能误删。
少于三次检测落点的死球簇不会命中。传球邻近停顿仍可能留在候选边缘。
这些风险已明确接受，不能把规则测试通过解释为真实识别准确率。

缓存轨迹报告和人工标注流程见 [融合验收](../hybrid-rally-validation.md)。
初版仅做缓存和规则验证。2026-09-08 优化已对三段原视频按原校准重新推理，精确
复现旧结果后冻结完整轨迹，再重放新版细化并核对指定片段。详见
[XML 优化报告](../hybrid-xml-optimization-20260908.md)。这不等同于整段逐帧人工批准，
也不包含本次新版的 Electron 实机交互、打包、签名或发布。
