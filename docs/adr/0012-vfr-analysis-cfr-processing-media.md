# ADR 0012：分析前可选 CFR 处理媒体，并保留原始 VFR

## 状态

已接受

## 背景

可变帧率视频的帧时间戳不均匀。球路检测、时间轴预览和精确剪辑若直接混用平均帧率，可能出现帧索引与时间的偏差；但文件身份、标定坐标和用户预览仍应对应用户选择的原始媒体。

## 决策

1. 标定始终读取原始媒体，并保存原始元数据到 `source_video`。
2. 新分析在标定完成后判断 VFR。设置“重编码为固定帧率”默认关闭：关闭时直接使用原始 VFR，并记录 `processing.mode=original_vfr`；开启时才生成带精确目标 FPS 的 CFR 派生媒体，分析结果的 `video` 指向实际处理媒体。
3. CFR 派生媒体按源指纹、目标 FPS、编码器和策略版本缓存，并随成功历史引用保留。关闭设置时不创建缓存；失败、取消或最后一个引用删除时清理缓存。
4. 在设置开启的前提下，空间不足、FFmpeg 非零退出或输出校验失败时使用原始 VFR 继续，并在 `processing.mode=vfr_fallback` 中记录稳定错误码；用户取消和应用退出终止任务且不回退。
5. 已有没有来源块的历史记录不自动迁移或转码；打开和导出继续使用旧 VFR 语义，重新分析才采用当前设置。

## 结果

- 设置开启后，分析、分析后预览、剪辑和新 Premiere XML 使用处理媒体；设置关闭时这些流程使用原始 VFR。历史指纹、封面、显示名称和默认输出名始终使用原始媒体。
- CFR 模式导出保持目标 CFR；原始 VFR、VFR 回退和旧记录保留现有 VFR 导出策略。
- normalized CFR 的 XML 目录包含完整 CFR 媒体副本并指向该副本；源本来就是 CFR 时 XML 继续引用原文件。
- 处理媒体会增加磁盘占用和转码等待，因此该选项默认关闭。设置开启时，进度明确分为标定、CFR 准备和分析，并把回退作为可见警告而非静默行为。
