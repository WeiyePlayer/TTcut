# TTcut v1.2.4

**简体中文** | [English](release-notes-v1.2.4.en.md)

`v1.2.4` 是 TTcut 1.2 功能线的正式修复版本，解决长视频在 CPU 导出时可能于关键帧探测阶段固定两分钟后失败的问题。

## 长视频 CPU 导出

- 旧流程会在分段编码前解码扫描整段视频以查找关键帧，并为 FFprobe 设置固定 120 秒期限。对于较长视频，这一步可能在尚未开始编码任何片段时被终止。
- 关键帧发现现在读取 FFprobe 的 packet-level 时间戳和关键帧标志，不再为此解码扫描全部画面。
- 导出相关的关键帧、音频包边界和流签名探测不再使用统一的 120 秒截止时间，长任务可以按视频长度和本机性能继续运行。

## 取消与组件设置

- 导出探测和输出校验接收任务取消信号；用户取消或退出应用时，当前 FFprobe/FFmpeg 进程树仍会被终止，并返回 `EXPORT_CANCELLED`。
- 视频处理组件解压和分析运行时自检不再依赖固定两分钟期限；组件安装的取消操作仍会中止对应子进程。
- 本次移除的是会错误终止合法长任务的统一期限，不表示失去取消能力或让已取消任务继续在后台运行。

## 影响范围

- 本版本不修改分析模型、动态 ROI、球轨迹、弹跳检测、回合识别、板数识别、剪辑边界或编码质量设置。
- 安装包继续使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单；未信任该证书的 Windows 仍可能显示“未知发布者”或 SmartScreen 提示。

## 验证

- PR #54 已通过 TypeScript 类型检查、Vitest（191 项通过、17 项跳过）、H.264 B 帧 packet/frame 关键帧等价集成测试、运行时脚本语法检查和固定 120 秒配置静态扫描。
