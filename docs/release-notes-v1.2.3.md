# TTcut v1.2.3

**简体中文** | [English](release-notes-v1.2.3.en.md)

`v1.2.3` 是 TTcut 1.2 功能线的正式版本，新增可验证的自定义回合片段编辑流程。

## 自定义片段编辑

- 自定义模式进入独立剪辑页面，可逐个选择或取消回合，并点击片段或列表行预览。
- 时间轴支持拖动片段开始和结束边界、拖动播放头定位；普通滚轮平移，`Ctrl` + 滚轮围绕指针位置缩放。
- 支持空格键播放/暂停，视频监视器使用 contain 适配，编辑时保持完整画面可见。

## 导出校验与状态

- 自定义导出显式传递最终 `segments`，Main 在启动 FFmpeg 前重新验证回合 ID、有限数值、源视频范围、最短帧长、排序和重叠。
- 非法范围统一返回 `INVALID_CUSTOM_SEGMENTS`；正好相接的合法片段可以合并，其他重叠不会被静默改写。
- 取消导出后保留本次自定义编辑状态；返回模式页时重置，避免旧编辑范围影响下一次导出。
- `all` 和 `highlight` 模式继续使用原有 Main 计算边界逻辑。

## 影响范围

- 本版本不修改分析模型、动态 ROI、球轨迹、回合识别或板数识别逻辑。
- 安装包继续使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单；未信任该证书的 Windows 仍可能显示“未知发布者”或 SmartScreen 提示。

## 验证

- PR #51 已通过 TypeScript 类型检查、Vitest（188 项通过、16 项跳过）和真实视频 Electron 流程验证，覆盖自定义时间轴交互与导出校验。
