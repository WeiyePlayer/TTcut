# TTcut Windows v1.3.2

**简体中文** | [English](release-notes-v1.3.2.en.md)

`v1.3.2` 是 TTcut Windows x64 的正式版本更新。本次修复了导出功能异常的错误。

## 问题修复

- 修复了导出功能异常的错误。
- 分段导出和逐回合导出会按各片段的实际累计时长更新进度，避免首个片段结束后进度提前接近完成。
- 快速流复制失败并回退到重新编码时，导出进度会在预留区间内继续更新；只有输出校验完成后才会显示 100%。
- 分析、导出等长时间任务运行期间会阻止应用被系统挂起，并在任务完成或取消后释放该状态，降低任务中途异常中断的风险。

## 版本说明

- macOS `v1.3.1` 已通过独立分支发布并锁定；Windows 版本因此从 `v1.3.0` 直接升级至 `v1.3.2`，未发布 Windows `v1.3.1`。
- 本次修复针对已经确认的导出进度和长任务挂起路径，不代表所有来源、编码格式和设备上的导出失败都已消除。

## 验证

- TypeScript 类型检查通过；Vitest 48 个文件、276 项测试通过，3 个文件和 17 项测试按条件跳过。
- 官网生产构建和 2 项渲染测试通过。
- 打包态 Electron 真实 CUDA 分析、单回合导出与最终预览流程通过，并重新校验了随包模型资源。
