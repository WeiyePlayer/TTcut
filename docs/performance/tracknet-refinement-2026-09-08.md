# TrackNet 独立运动细化与实拍回归（2026-09-08）

本轮承接细节审查，修改了生产 Python TrackNet 回合判定。固定 ROI scale=1.0、检测置信度0.36，未改 BlurBall 算法、模型或历史。已修复这三段视频中确认的两处完整回合误拆、一处纯传球误收、一处两次发球误合并；全量筛查最终193个回合间隙，未发现新增误拆。这是当前样本的复核结论，不是所有视频零误拆的保证。

## 实现与取舍

新增 `worker/ttcut_worker/tracknet_motion.py`，只处理 TrackNet 已接受候选：

- 原1.5秒可靠片段桥接保留。超过1.5秒、至多4.5秒的间隙，必须有持续且具有横纵跨度的高球飞行观测才连接。没有检测到球本身不构成连接或拆分的证据。
- 短片段具有持续单向慢传球、且有效快速运动不足时才剔除。单向性检查完整轨迹累计位移，防止把往返击打误判成传球。
- 新拆分必须同时观察到持续低运动停顿、随后的慢传球，以及两侧各自的击打证据与最短长度。第二段记录 `lead_in_start_time_seconds`，约束导出前补时，避免把传球重新加回来。
- 尾段依据慢传球、桌面以下落球、稀疏尾点等证据收紧。弱证据保留最后有效运动后1秒余量；不会统一按参考边界或固定长度裁尾。曾尝试更紧的边界，但画面显示会裁掉慢速最后一拍，已否决。
- 距离按原ROI宽高归一化，时间窗按源时间戳计算。运行结果记录 motion policy version 2、长桥接上限与尾段余量。

## 全片参考一致性

完整真实推理轨迹通过当前生产函数重新计算，未重复模型推理。与原有BlurBall历史一对一匹配；历史不是人工真值。

1-193的F1下降来自把参考漏收的两次真实发球正确拆开，增加一个无法匹配的输出；这说明不能只追求参考分数。

以IoU≥0.3匹配计算边界，匹配数182→181，起点平均绝对误差0.616→0.617秒，终点0.834→0.738秒；起止同时在±0.5秒内60/182→61/181。匹配集合变化，且参考有错误，不能把此差值解释为人工真值上的精确提升。起点没有得到系统性改善，仍有模型漏检造成的偏晚开始/提前结束。

## 验证与复现

- 119项Python测试通过，包含TrackNet、worker契约、共享可见性和BlurBall运动回归。
- 新增12个实拍语义夹具：连续回合不误拆、真实新发球不误连、传球排除、最后一拍保护；另外测试坐标缩放、时间平移、输入不变，以及只有检测缺失时不得擅自拆分/长桥接。
- PyAV按源PTS取帧：对所有修改尾段及11处长间隔动态候选详细复核；最终193个回合间隙均用4帧筛查。有疑点处使用更密集图集。不是全片每帧人工标注，也没有计算真实总体准确率。
- 三份完整轨迹用 `scripts/verify-tracknet-motion.py <三个完整阈值缓存JSON> --output <结果JSON>` 重放。输入为 `benchmark-tracknet-thresholds.py` 生成的含trajectory缓存，不是汇总JSON；需要项目Python依赖。回归夹具可不依赖原视频运行。
- 本机命令：`PYTHONPATH=/tmp/ttcut-tracknet-deps /Users/weiye/TTcut-ios/tools/model-conversion/.venv/bin/python -m pytest worker/tests/test_tracknet_motion.py worker/tests/test_tracknet_rallies.py worker/tests/test_analysis.py worker/tests/test_analysis_intervals.py worker/tests/test_visibility_rallies.py worker/tests/test_visibility_stability.py worker/tests/test_tracknet_threshold_benchmark.py worker/tests/test_blurball_rallies.py worker/tests/test_blurball_motion_regression.py -q`。

证据在 `artifacts/tracknet-refinement-2026-09-08/`：`results.json`含前后完整匹配、边界与源文件哈希；`replay.json`含独立重放结果和输入缓存哈希；8张重点图集与3份复核清单。清单中的`.tasks`路径保留本机完整复核图集位置，未全部复制入版本控制。
