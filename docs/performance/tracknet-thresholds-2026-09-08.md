# TrackNet 检测阈值对照（2026-09-08）

在固定 ROI 缩放 `1.0`、固定回合判定参数的这组三视频测试中，阈值 `0.36` 与 `0.365` 的整体一对一匹配 F1（时间 IoU ≥ 0.50）并列最高；`0.36` 的匹配 IoU 总和更高，因此采用 `0.36`。该结论是对指定 BlurBall 历史结果的一致性比较，不是人工标注准确率，也未验证其他视频上的泛化。

相比原值 `0.35`，整体 F1 从 79.49% 提升到 80.20%，匹配数从 157 增至 158。WTT 和 mmexport 各增加一个匹配，1-193 减少一个；这是小幅的整体改善，并非每个视频均改善。TrackNet 默认阈值已设为 `0.36`，ROI 缩放仍为 `1.0`，BlurBall 的阈值、算法及历史记录未改动。

推荐值优先考虑较严格的边界一致性：若改用 IoU ≥ 0.30，`0.325` 的 F1（93.13%）会高于 `0.36`（92.39%），因此不能称 `0.36` 在所有评价标准下都最优。

## 方法

- 参考为截图对应的三条 BlurBall 历史记录，共 196 个回合；先复制记录快照，再只读使用。
- 模型权重、标定、ROI 边界、缩放 `1.0`、视频解码和回合判定参数全部固定，唯一实验变量是检测阈值。
- 同一窗口只运行一次 TrackNet；各阈值独立提取候选点并维护轨迹历史。没有将某档轨迹简单过滤来冒充另一档。
- 每个阈值在完整视频上运行；0.35 的全部轨迹点、ROI 和回合边界与独立推理基线逐项完全一致。
- 匹配标准为时间区间 IoU ≥ 0.50 的一对一匹配；F1 = 2 × 匹配数 /（预测数 + 参考数）。F1 相同时按匹配 IoU 总和比较。
- 0.30 IoU 的较宽松匹配、逐回合边界误差和全部预测区间同时保存在 `artifacts/tracknet-thresholds-2026-09-08/comparison.json`。
