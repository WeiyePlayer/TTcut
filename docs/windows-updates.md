# Windows 应用内更新

本文描述当前源码的更新流程；已安装旧版本的行为需要安装包含此改动的新构建后才会改变。

- Windows x64 正式包在启动约 10 秒后检查更新。只有已打包且包含 `app-update.yml` 的应用启用检查；macOS、开发环境及缺少该配置的本地包不启用。
- 发现新版本时先提示版本号，不下载。用户可选择“立即更新”“稍后提醒”或“跳过此版本”。
- “立即更新”开始下载并验证更新包。下载完成后可选择“立即重启”安装或“稍后重启”。普通退出不会自动安装。
- “稍后提醒”关闭本次启动中该版本的提示，仍可通过设置中的“查看更新”重新打开；下次启动可再次提醒。
- “跳过此版本”将版本号写入 Electron `userData` 下的 `update-preferences.json`。后续启动不再自动提示该版本，更高版本仍会提示。设置中的“检查更新”忽略跳过记录，允许重新选择。
- 下载期间不重复检查或开始另一份下载；已下载的更新保留“立即重启”入口。下载或签名验证失败不会安装，设置页显示错误及适用的重试或手动下载入口。

更新状态由 Main 管理。Preload 的 `downloadUpdate(version)` 和 `skipUpdate(version)` 只传递版本选择，Main 核对版本是否与当前待选更新一致；原有签名更新清单校验继续执行。
