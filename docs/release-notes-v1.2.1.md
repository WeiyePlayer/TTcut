# TTcut v1.2.1

**简体中文** | [English](release-notes-v1.2.1.en.md)

`v1.2.1` 是 TTcut 1.2 功能线的正式修复版本，修复异常输入帧时长在分段导出中造成音画时长偏差的问题。

## 音画同步修复

- 部分源视频包含明显异常或不均匀的单帧时长。新版 FFmpeg 的 `setpts` 会保留相关帧率元数据，导致裁剪后的画面时长与音频时长不一致，最终触发 `EXPORT_AV_SYNC_MISMATCH`。
- OpenH264 与 x264 的单片段和多片段裁剪路径现在使用 `setpts=PTS-STARTPTS:strip_fps=1`，在重新生成时间戳时移除继承的帧率元数据。
- 导出继续使用 `-fps_mode vfr` 保留可变帧率，不增加固定 `-r` 参数，也不会把源视频强制转换为固定帧率。
- 静音视频的分段拼接清单会写入每个所选片段的明确时长，避免异常帧时长延续到最终输出。

## 校验与诊断

- 输出仍须通过文件可读性、分辨率、H.264、AAC、时间戳、旋转、元数据、总时长和音画同步校验。
- 音画时长偏差允许范围仍为 0.1 秒，没有放宽。
- 校验失败时会记录视频时长、音频时长、实际偏差和允许范围，便于区分真正的音画不同步与其他导出错误。
- 结构有效但总时长超出媒体感知预算的输出恢复机制保持不变。

## 影响范围

- 修复覆盖默认 OpenH264 和可选 x264 编码组件。
- 不修改剪辑区间、片段选择、输出分辨率、编码质量或文件命名规则。
- 不修改 TrackNet、可选双模型、动态 ROI、球轨迹、反弹检测、回合分组或 `bounce_count`。

## 更新与签名

- `v1.2.0` 用户可以通过应用内更新升级到本版本。
- 安装包继续使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单。未信任该证书的 Windows 仍可能显示“未知发布者”或 SmartScreen 提示。

## 验证边界

- 自动化测试覆盖异常帧时长清理、VFR 保留、静音片段时长、音画诊断信息和分段拼接时间戳。
- 本版本通过 TypeScript 类型检查、`168` 项 Vitest 测试和 `65` 项 Python worker 测试；另有 `12` 项因运行环境不适用而跳过。
- 真实 OpenH264/x264 分段导出集成验证共 `9` 项，覆盖解码、DTS 单调性、VFR、多片段输出总时长和音画时长偏差。
