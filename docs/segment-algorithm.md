# 回合选择与剪辑段算法

## 选择

Main 从最近一次经验证的 `AnalysisResultV1` 处理选择。

- **所有回合**：全部有效回合。
- **精彩回合**：严格使用 `bounce_count > X`，X 只允许 3、5、7。
- **自定义**：Renderer 提交每个已选回合的显式最终时间段；Main 按下文规则重新验证。

选择前按 ID 精确去重，再按开始时间和稳定 index 排序。当前 `bounce_count` 是弹跳代理，不是实际击球计数。

## 原始 5 秒分组

对相邻回合计算：

```text
gap = next.start_time_seconds - currentGroup.rawEnd
```

- `gap < 5.0`：合并到当前原始组；
- `gap >= 5.0`：开始新组；
- 恰好 5.000 秒不合并。

比较使用极小浮点容差，确保 4.999 合并而 5.000 分开。

## 前后扩展与二次去重

每个原始组只扩展一次：

```text
start = max(0, rawStart - preRoll)
end   = min(videoDuration, rawEnd + 1.0s finalRallyTail + postRoll)
```

每个剪辑片段只在组内最后一个回合结束后增加 1 秒固定收尾，再完整应用用户选择的回合后时间；组内较早回合不增加这 1 秒。前置时间仍只允许 1.5、2.5、5 秒，后置仍只允许 0.5、1、2、4 秒。若所需结束时间超过源视频末尾，则直接在源视频末尾结束。若扩展后的下一组 `start <= previous.end`，再次合并，以避免重复画面。

非法/非有限时间、结束不晚于开始、重复 ID、空结果和无效视频时长均不会启动 FFmpeg。

## 自定义回合片段

自定义草稿为每个回合建立一个独立片段，不应用原始 5 秒分组。默认值为：

```text
start = max(0, rally.start - preRoll)
end   = min(videoDuration, rally.end + 1.0s finalRallyTail + postRoll)
```

默认全部选中。相邻默认片段发生重叠时，在重叠区域中点拆分，形成一条无重叠轨道。片段不能整体移动；左右手柄可裁入或避开检测回合，但必须至少保留 `1 / fps` 秒。拖拽下限/上限依次为源视频边界、当前片段的单帧下限和相邻已选片段边界。

取消选择后片段从轨道隐藏，也不再约束邻居，但保留已编辑起点供列表播放。重新勾选时先尝试恢复保存范围；如与已选片段冲突，则只把连续冲突区域恢复为默认范围并重新按中点拆分。

自定义导出合同不携带全局前后时间。Main 对提交顺序逐段验证：

- 回合 ID 必须存在且唯一；
- 起止必须为有限数值，位于 `[0, videoDuration]`；
- 结束严格晚于开始，且时长不少于一个源视频帧；
- 时间段必须已排序且不重叠。

相接时间段可合并为一个 `CutGroup`；任何失败都以 `INVALID_CUSTOM_SEGMENTS` 拒绝，FFmpeg 不会启动。

## 自定义产物导出

自定义页面可选择生成分段视频、Premiere XML，或保持默认的合并 MP4。所有模式都先执行相同的显式片段验证；只有合并 MP4 会将恰好相接的片段合并为 `CutGroup`。分段视频保留每个已选回合的独立起止范围，并按选择顺序命名。Premiere XML 是引用原始视频的 FCP7 `xmeml` v4 文件，按选择顺序连续排布 V1/A1 片段；可变帧率素材按 `nominal_fps`（无此值时按 `fps`）量化到最近帧。

## 已覆盖边界

- 4.999、5.000 和大于 5 秒；
- 三个连续短间隔；
- 乱序和重复回合；
- 视频首尾截断；
- 扩展后重叠；
- 严格精彩阈值；
- 自定义默认中点拆分、单帧下限和隐藏邻居；
- 自定义未知/重复回合、非有限、越界、过短、乱序和重叠时间段；
- 自定义相接区间合并。
