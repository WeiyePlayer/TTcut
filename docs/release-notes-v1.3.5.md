# TTcut v1.3.5

**简体中文** | [English](https://github.com/WeiyePlayer/TTcut/blob/v1.3.5/docs/release-notes-v1.3.5.en.md)

`v1.3.5` 是面向 Windows x64 与 macOS 15+ Apple Silicon 的正式版本更新。两个平台统一自定义剪辑空格播放控制；Windows 另外改善 HEVC 预览和安装器兼容性。本次重新构建发布，不沿用上一轮安装包。

## 自定义剪辑播放

- 空格键统一用于暂停或继续播放。焦点停留在回合行、复选框、播放模式或其他按钮上时，不会重新播放回合、改变勾选或误触按钮。
- 长按空格不会连续切换，输入法组合输入期间不会拦截空格；Enter 仍保留原有的按钮和回合激活行为。

## Windows HEVC 兼容预览

- Windows 上的 HEVC 视频会直接准备兼容预览，不再以元数据或首帧可读作为后续回合跳转可用的充分条件。
- 兼容预览切换时会保留播放位置与播放意图，降低自定义回合定位后黑屏或无法继续播放的概率。

## macOS 功能与平台边界

- 保留原生 Core ML 连续运动回合分析、独立板数检测及“多选”菜单，可按 1–10 的最低板数批量勾选回合；缺失板数元数据的旧记录明确提示重新分析。
- 保留相邻片段边界按拖动方向选择调整侧及不遮挡轨道的播放头显示。
- macOS 继续使用原生兼容预览，不把 Windows HEVC 或 NSIS 安装器改动描述为 macOS 能力。
- Windows 本次保持逐帧 BlurBall 推理；撤回上一轮时间采样提速描述，不宣称速度或识别质量提升。

## 安装包

- **Windows x64 · v1.3.5**：`TTcut-1.3.5-x64-Setup.exe`，提供包含必需运行资源的完整安装包，可一次完成安装。
- 安装信息改由 NSIS 安装器原生写入并立即回读验证，不再调用 PowerShell，因此企业执行策略、语言模式、PATH 或 .NET 状态不会阻断注册步骤；失败时会在回滚目录外保留诊断日志。
- 安装包使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单。未信任该证书的 Windows 环境仍可能显示“未知发布者”或 SmartScreen 提示。
- **macOS 15+ · Apple Silicon · v1.3.5**：`TTcut-1.3.5-arm64-Setup.dmg`（推荐）与 `TTcut-1.3.5-arm64-Setup.zip`，内置原生分析及媒体处理资源，不支持 Intel Mac。
- macOS 包使用临时签名且未经过 Apple 公证；首次打开若被拦截，请在“系统设置 > 隐私与安全性”中确认允许。软件内更新继续禁用。

## 验证

- macOS 重新发布验证：类型检查、139 项相关回归测试、17 项 macOS 边界测试和启用原生依赖的 Swift 测试通过；打包应用多选及共享边界 6 项验收通过。
- 在 macOS 主机上，独立 Electron 真实视频播放 18 项及缩放 4 项通过；其测试桥接平台为 `win32`，不作为 Windows 实机验收。
- macOS DMG 挂载、打包应用签名完整性、29 个 arm64 原生文件的依赖边界，以及 DMG/ZIP 大小和 SHA-256 摘要校验通过；这些检查不等同于 Apple 公证。
- Windows 发布验证：TypeScript 类型检查通过；Vitest 共 62 个测试文件、423 项测试通过，另有 6 个文件、25 项测试按既有条件跳过；Python 共 222 项回归测试通过。
- 官网生产构建及 2 项渲染测试通过。
- Windows Electron 自定义播放真实媒体验收共 18 项通过，覆盖空格控制、定位、连续播放、临时预览和结果预览。
- 完整安装包通过固定模型资产、辅助式 NSIS、安装结构和运行资源交付边界校验；应用、卸载程序和外层安装包均带固定证书与 RFC 3161 时间戳，签名更新清单、SBOM 和 SHA-256 摘要已生成。
