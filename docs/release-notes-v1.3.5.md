# TTcut Windows v1.3.5

**简体中文** | [English](https://github.com/WeiyePlayer/TTcut/blob/v1.3.5/docs/release-notes-v1.3.5.en.md)

`v1.3.5` 是面向 Windows x64 的正式版本更新。本次重点改善自定义剪辑播放、HEVC 预览和安装器兼容性。

## 自定义剪辑播放

- 空格键统一用于暂停或继续播放。焦点停留在回合行、复选框、播放模式或其他按钮上时，不会重新播放回合、改变勾选或误触按钮。
- 长按空格不会连续切换，输入法组合输入期间不会拦截空格；Enter 仍保留原有的按钮和回合激活行为。

## Windows HEVC 兼容预览

- Windows 上的 HEVC 视频会直接准备兼容预览，不再以元数据或首帧可读作为后续回合跳转可用的充分条件。
- 兼容预览切换时会保留播放位置与播放意图，降低自定义回合定位后黑屏或无法继续播放的概率。

## 安装包

- **Windows x64 · v1.3.5**：`TTcut-1.3.5-x64-Setup.exe`，提供包含必需运行资源的完整安装包，可一次完成安装。
- 安装信息改由 NSIS 安装器原生写入并立即回读验证，不再调用 PowerShell，因此企业执行策略、语言模式、PATH 或 .NET 状态不会阻断注册步骤；失败时会在回滚目录外保留诊断日志。
- 安装包使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单。未信任该证书的 Windows 环境仍可能显示“未知发布者”或 SmartScreen 提示。
- 本次 Release 草稿暂不发布，也不推送 `v1.3.5` 标签。

## 验证

- TypeScript 类型检查通过；Vitest 共 62 个测试文件、423 项测试通过，另有 6 个文件、25 项测试按既有条件跳过；Python 共 222 项回归测试通过。
- 官网生产构建及 2 项渲染测试通过。
- Windows Electron 自定义播放真实媒体验收共 18 项通过，覆盖空格控制、定位、连续播放、临时预览和结果预览。
- 完整安装包通过固定模型资产、辅助式 NSIS、安装结构和运行资源交付边界校验；应用、卸载程序和外层安装包均带固定证书与 RFC 3161 时间戳，签名更新清单、SBOM 和 SHA-256 摘要已生成。
