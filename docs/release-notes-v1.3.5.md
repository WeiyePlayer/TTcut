# TTcut Windows v1.3.5

**简体中文** | [English](https://github.com/WeiyePlayer/TTcut/blob/v1.3.5/docs/release-notes-v1.3.5.en.md)

`v1.3.5` 是面向 Windows x64 的正式版本更新。本次新增按板数批量选择自定义回合，改善时间线相邻边界交互，并通过受约束的时间采样降低 BlurBall 分析耗时。

## 自定义回合多选

- 自定义剪辑列表新增“多选”菜单，可一键全选，或输入 1–10 的最低板数并批量选择达到阈值的回合；“取消全选”仍可直接使用。
- 连续运动结果现在携带独立的板数检测元数据，Windows 自定义剪辑复用 BlurBall 已有落点结果显示和筛选板数。
- 旧分析记录没有板数元数据时，板数筛选会禁用并明确提示重新分析，不会把缺失数据当成 0 板。

## 时间线交互修复

- 当两个相邻片段共用同一边界时，向左拖动会调整左侧片段末尾，向右拖动会调整右侧片段开头；一次拖动中选定的片段不会因反向移动而改变。
- 播放头只在标尺区域捕获拖动，轨道上的红线改为纯显示，不再遮挡片段点击或边界调整。
- 调整片段边界时显示实际变化量，并继续遵守相邻片段、最短时长和视频范围约束。

## BlurBall 分析吞吐

- 完整分析默认使用时间采样间隔 3：仍解码并保留每个源帧的真实时间戳，但只对 F1/F4/F7、F10/F13/F16 等采样帧执行模型推理。
- 只在前后采样帧都真实检出球且时间戳有效时，对中间位置作时间加权插值；不跨越采样漏检、不外推尾帧，插值点也不作为落点证据。
- 两阶段分析的精分析区间仍逐帧运行；历史结果新增采样间隔和插值统计，旧记录继续兼容。
- 在一个 20,131 帧冻结视频、固定模型/标定/阈值的单次 RTX 4060 Laptop GPU 对照中，相比逐帧基线，模型推理耗时降低约 61.4%，基准总耗时降低约 25.3%。完整解码成本仍然存在，这不是“两倍提速”承诺。
- 该对照没有人工逐回合真值，stride 3 的回合与落点结果也与逐帧基线存在差异，因此本版本只确认该样本的速度收益，不宣称识别质量等价或适用于所有视频与设备。

## 安装包

- **Windows x64 · v1.3.5**：`TTcut-1.3.5-x64-Setup.exe`，提供包含必需运行资源的完整安装包，可一次完成安装。
- 安装包使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单。未信任该证书的 Windows 环境仍可能显示“未知发布者”或 SmartScreen 提示。
- 本次 Release 草稿暂不发布，也不推送 `v1.3.5` 标签。

- 官网生产构建及 2 项渲染测试通过。

- 完整安装包通过固定模型资产、辅助式 NSIS、安装结构和运行资源交付边界校验；应用、卸载程序和外层安装包均带固定证书与 RFC 3161 时间戳，签名更新清单、SBOM 和 SHA-256 摘要已生成。
