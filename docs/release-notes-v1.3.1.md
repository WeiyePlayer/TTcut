# TTcut macOS v1.3.1

**简体中文** | [English](release-notes-v1.3.1.en.md)

`v1.3.1` 是面向 macOS 15+ Apple Silicon 的更新版本，重点优化导出性能并修复部分已知问题。Windows 当前稳定版本仍为 `v1.3.0`。

## 导出性能优化

- 分段导出会先定位到每个目标片段附近再开始解码，避免每个片段都从视频开头重复处理。
- 取消固定的双线程限制，由 FFmpeg、x264 和 x265 根据设备自动调度编码与滤镜线程。
- 在同一真实视频、相同 14 个合并片段和 211.174 秒目标时长的对照中，导出耗时由约 682.301 秒降至 145.636 秒，约为原来的 4.68 倍速度，耗时减少约 78.66%。旧耗时来自精度为一秒的文件时间戳，因此属于近似值；不同设备、编码格式和视频内容不会得到完全相同的提升。
- 对照输出的解码视频 SSIM 为 `1.000000`，解码音频 SHA-256 一致，视频与音频帧数也一致。

## 问题修复

- 修复 macOS“连续运动”回合识别选项未实际接入原生分析的问题。选择“连续运动”后，原生 Worker 现在会执行连续运动算法并返回对应回合结果。
- 修复部分已知问题，并清理不再使用的旧 macOS 界面实现，当前 macOS 产品继续使用 Electron 界面与原生 Core ML、媒体处理服务。

## 平台与安装包

- **macOS 15+ · Apple Silicon · v1.3.1**：提供 DMG（推荐）和 ZIP，内置原生 Core ML 分析及媒体处理运行资源，不支持 Intel Mac。
- 同时提供 `latest-mac.yml` 发布元数据；当前 macOS 应用仍未启用自动更新。
- 安装包使用临时签名且未经过 Apple 公证。首次打开若被系统拦截，请在“系统设置 > 隐私与安全性”中确认允许。
- Windows 当前稳定版本仍为 `v1.3.0`，不包含在本次 macOS 发布资产中。
