# TTcut v1.2.8

**简体中文** | [English](release-notes-v1.2.8.en.md)

`v1.2.8` 是 TTcut 1.2 功能线的正式版本，继续完善自定义剪辑页面与桌面端界面，并修复了一批流程和交互问题。

## 自定义剪辑与界面

- 继续优化自定义剪辑页面的时间轴、回合操作和视觉反馈，让新增、删除、预览及调整片段边界的过程更清晰稳定。
- 优化桌面端布局、控件状态、上传引导与文字表现，改善小窗口和高 DPI 下的操作体验。
- 时间轴滚动范围会限制在实际内容边界内，避免滚动后出现空白区域或定位不一致。

## 本地分析与流程修复

- 新视频统一使用当前内置的本地分析流程；设置页不再显示已停用的旧选项。
- 启动时会自动清理旧版本遗留的已停用设置，同时保留语言、标定和剪辑时长等有效偏好。
- 精简安装包中的已停用资源及相关维护脚本，降低本地安装包体积。
- 修复批量任务、设置迁移及若干界面交互问题。

## 范围说明

- 本版本不提供基于新增标注集的识别准确率或动态 ROI 效果声明；实际结果仍取决于视频画面、标定质量和本机环境。
- 合并 MP4、逐回合 MP4 与 Premiere 可导入 XML 的导出方式继续保留。
- 安装包继续使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单。未信任该证书的 Windows 环境仍可能显示“未知发布者”或 SmartScreen 提示。

## 验证

- `npm run typecheck` 通过；串行 Vitest：44 个文件通过、218 个测试通过、17 个跳过。
- Worker 测试：35 个通过；官网构建和渲染测试均通过。
- Electron 端到端测试：9 个通过、1 个按环境条件跳过，覆盖真实组件导入、125%/150%/200% DPI、真实视频分析与导出、批量自动/手动恢复及首次组件设置。
- 正式安装包签名、更新清单签名和发布资产校验已在发布前完成。
