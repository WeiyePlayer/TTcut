# TTcut v1.2.0

**简体中文** | [English](release-notes-v1.2.0.en.md)

`v1.2.0` 是 TTcut 1.2 功能线的首个正式版，包含可选的 CUDA 双模型识别档位、动态 ROI 分析、导出恢复能力，以及单视频和批量任务的工作流改进。TrackNet 仍是默认模型。

## 可选双模型识别

- 设置页提供“默认模型”和 CUDA 专用“新模型”两个球识别档位。新模型使用 SegFormer++ B2 主模型和 WASB 辅模型进行一致性过滤。
- 升级不会自动改变已有模型选择，也不会自动下载新模型。只有用户主动选择新档位时才安装对应权重。
- 新档位要求 CUDA 分析组件。权重缺失、损坏或 CUDA 不可用时，应用会阻止分析并给出修复入口，不会静默回退到 TrackNet。
- 单视频、批量任务和历史记录会保存实际使用的模型档位、ROI 及主辅输入尺寸。

## 动态 ROI 与分析输入

- 两个档位共享标定生成的动态 ROI。TrackNet 继续采用 1.25× 采样策略。
- 新档位根据解码后的实际视频分辨率和 ROI 尺寸计算输入：主模型采用 1/2 宽高并对齐到 4 像素，辅模型采用 2/5 宽高并对齐到 8 像素。
- 主辅检测结果映射回源视频坐标后进行一致性过滤，再接入现有轨迹、反弹检测、回合分组和 `bounce_count` 流程。
- 包含色彩预处理、热图亚像素定位、短缺失轨迹补全和反弹平台消歧修复。

## 导出可靠性与恢复

- 导出校验不再使用固定的时长阈值，而是根据视频帧率、音频边界和合并片段数量计算媒体感知容差。
- 多片段 VFR/AAC 输出会同时对照编码片段时长和原始选择区间，减少累计舍入误差造成的误报。
- 分辨率、编码、音频、音画同步、时间戳、旋转和元数据等结构检查会先执行。结构有效但时长仍超出预算的结果会使用防冲突文件名保留，并在单视频和批量流程中提供恢复操作。
- 这项改动不会掩盖真正损坏、缺少音视频流或无法读取的导出文件。

## 工作流改进

- 在“自动剪辑”“历史剪辑”和“设置”之间切换时，正在运行的单视频或批量任务会继续保留，不再因页面切换丢失处理界面。
- 活跃任务期间会阻止互相冲突的组件设置和历史操作。
- 批量任务新增“全部成功后关闭 Windows”选项。失败、取消、等待人工标定或仍有任务运行时不会触发关机。
- 设置页显示高精度双检测模型的安装状态和实际组件路径。

## 模型下载

双模型权重不写入 Git，也不打入安装包。应用从固定的 [dual-ball-models-1.0.0 运行时资产 Release](https://github.com/WeiyePlayer/TTcut-runtime-assets/releases/tag/dual-ball-models-1.0.0) 按需下载：

- `ttcut-ball-main-segformerpp-b2-1.0.0.pt`：99,091,962 字节；SHA-256 `f2e8b1050866a8bba540f731b379ee510a792f1af91996cb3bbc9cc0953f096e`。
- `ttcut-ball-aux-wasb-1.0.0.pt`：6,085,114 字节；SHA-256 `73bfe091d22dcca40f2ab19671370bb0f4236b451041dcbe72e8feefdb8539a0`。

下载支持重试、续传、逐文件哈希校验和双文件原子安装，也可从设置页手动导入两个原始权重。

## 更新与兼容性

- `v1.2.0` 使用稳定版 `latest.yml` 更新通道。稳定版和 `v1.2.0-beta.1` 用户均可升级到本版本。
- 安装包继续使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单。未信任该证书的 Windows 仍可能显示“未知发布者”或 SmartScreen 提示。
- Windows x64 仍是官方目标；应用不会按 Windows build 编号进行硬拦截，实际兼容性由组件和运行环境自检决定。

## 验证边界

- TypeScript 检查通过；Vitest 共 166 项通过、10 项按环境跳过；Worker 测试共 65 项通过。
- 固定双模型权重通过大小与 SHA-256 校验；真实 CUDA 严格加载得到主模型 `[1, 1, 135, 240]`、辅模型 `[1, 1, 432, 768]` 输出形状。
- OpenH264/x264 真实多片段导出集成测试共 7 项通过；真实 Electron 流程完成 CUDA 分析、单回合导出和最终预览。
- 正式 NSIS 构建通过内置模型、组件目录、安装布局、Fuse、Authenticode、RFC 3161 时间戳和签名更新清单校验。
- 真实权重验证不包含人工标注，因此仅确认模型加载、处理流程和客观输出，不宣称相对准确率。发布验证没有触发真实 Windows 关机；关机保护由自动化测试覆盖。
