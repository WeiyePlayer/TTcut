# TTcut v1.3.4

**简体中文** | [English](https://github.com/WeiyePlayer/TTcut/blob/v1.3.4/docs/release-notes-v1.3.4.en.md)

`v1.3.4` 是面向 Windows x64 与 macOS 15+ Apple Silicon 的正式版本更新。本次在两个平台新增自定义剪辑播放模式和时间轴缩放工具，增强播放恢复与运行诊断；Windows 版本还改为由用户决定何时下载及安装更新，并强化 GPU 推理诊断。

## 自定义剪辑播放与时间轴

- 自定义剪辑新增“原片播放”和“回合播放”。回合播放会按时间顺序连续播放视频轨中已勾选的片段并跳过间隔，片段边界或勾选状态改变后立即按新范围生效。
- 点击未勾选回合可临时预览，不改变选择和导出内容；播放模式只影响监视窗口，不修改分析结果、历史记录或导出格式。
- 新增“缩放视频轨”工具，可在时间轴标尺或片段轨道上以鼠标位置为中心滚轮缩放；原有 Ctrl/⌘＋滚轮入口继续可用。

## Windows 应用内更新

- 发现新版本时先显示提示，不再自动开始下载。可以选择“立即更新”“稍后提醒”或“跳过此版本”。
- 下载并验证完成后，可以选择立即重启安装或稍后重启；普通退出不会自动安装。
- 跳过的版本会记录在本机，更高版本仍会继续提示；设置中的手动检查会忽略跳过记录，允许重新选择。

## 播放恢复与运行诊断

- 修复媒体元数据加载或兼容代理准备期间点击目标被覆盖的问题，并在播放请求被中断后按最后一次播放或暂停意图恢复。
- 完全停帧且时间不推进时也会触发兼容预览恢复；常规可解码视频仍直接播放，分析和导出源文件不变。
- Windows BlurBall 在已知 FP16 风险显卡上直接使用 FP32；其他 CUDA 设备遇到 NaN/Inf 时自动回退并重算。持续无效会明确失败，不再静默保存为成功的零回合结果。
- Windows 日志新增实际 GPU、精度、批次和检出统计；两个平台均补充进程退出信息，并在本地保存不上传的崩溃转储，便于继续定位原生故障。

## 已知边界

- GTX 1660 Super 的零回合反馈有公开兼容性资料和故障注入支持，但尚未在用户的实际显卡上闭环复测；本次不把该硬件问题表述为已经实机确认解决。
- 历史反馈中的导出末尾闪退根因仍未确定。本版本补齐了导出阶段、进程退出和本地转储诊断，不宣称该未知原生崩溃已经修复。

## 安装包

- **Windows x64 · v1.3.4**：`TTcut-1.3.4-x64-Setup.exe`，提供包含必需运行资源的完整安装包，可一次完成安装。
- 安装包使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单。未信任该证书的 Windows 环境仍可能显示“未知发布者”或 SmartScreen 提示。
- **macOS 15+ · Apple Silicon · v1.3.4**：`TTcut-1.3.4-arm64-Setup.dmg`（推荐）与 `TTcut-1.3.4-arm64-Setup.zip`，内置原生 Core ML 分析及媒体处理运行资源，不支持 Intel Mac。
- macOS 安装包使用临时签名且未经过 Apple 公证；首次打开若被系统拦截，请在“系统设置 > 隐私与安全性”中确认允许。当前不提供软件内更新。

## 验证

- TypeScript 类型检查通过；Vitest 共 61 个测试文件、409 项测试通过，另有 6 个文件、25 项测试按既有条件跳过；Python 共 222 项回归测试通过。
- 官网生产构建及 2 项渲染测试通过。
- Windows x64 打包态 Electron 的自定义播放 16 项与时间轴缩放 4 项真实检查通过，包含跳转后的时间位置和解码帧推进；打包应用启动冒烟通过。
- 完整安装包通过固定模型资产、辅助式 NSIS、安装结构和运行资源交付边界校验；应用、卸载程序和外层安装包均带固定证书与 RFC 3161 时间戳，签名更新清单、SBOM 和 SHA-256 摘要已生成。
- macOS 通过 TypeScript、专用 Vitest、原生 Swift、Core ML 模型、正式 Electron 流程、打包界面、arm64 包体签名及 DMG/ZIP 交付校验。
