# TTcut v1.2.2

**简体中文** | [English](release-notes-v1.2.2.en.md)

`v1.2.2` 是 TTcut 1.2 功能线的正式修复版本，改进多片段导出的音画同步、拼接时间戳和可播放结果恢复。

## 分段拼接与音画同步

- 独立编码的 AAC 片段可能产生细小的包时长舍入差异，多个片段拼接后会累积为可见的音画时长偏差。拼接清单现在使用每个编码后片段的实测时长，并增加基于视频 time base 的微小保护量。
- 有音频的拼接输出会在异步重采样后将音频安全补齐到画面端点，并由最短流结束输出，避免音频短于画面或无限延长。
- 独立编码的 x264 片段关闭 B 帧，避免拼接边界出现相等或回退的解码时间戳；默认 OpenH264 和可选 x264 路径均覆盖本次验证。
- 这项修复针对 AAC 舍入累积和 x264 拼接时间戳，不表示所有 `EXPORT_CONCAT_FAILED` 都由同一原因造成。

## 可播放结果恢复

- 如果 FFmpeg 已生成可播放视频，但后续校验、重命名或历史记录步骤发生异常，TTcut 会先探测文件，再保留到正常输出路径或带 `_with_warning` 的防冲突文件名。
- 单视频流程会显示正常的导出预览页，并附加警告面板、错误代码、本地化说明、技术详情和日志文件夹入口。
- 批量流程会把该项目标记为已完成但带警告，保留预览与打开文件操作，并继续处理其余项目。
- 无法读取的输出不会被当作成功结果保留；用户主动取消仍进入取消流程。

## 影响范围

- 不修改用户选择的剪辑区间、输出分辨率、编码质量或正常文件命名规则。
- 不放宽音画同步、时间戳、编码、分辨率和媒体可读性校验；警告状态明确表示后续处理发生异常，而不是宣称文件通过全部校验。
- 不修改 TrackNet、可选双模型、动态 ROI、球轨迹、反弹检测、回合分组或 `bounce_count`。

## 更新与签名

- `v1.2.1` 用户可以通过应用内更新升级到本版本。
- 安装包继续使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单。未信任该证书的 Windows 仍可能显示“未知发布者”或 SmartScreen 提示。

## 验证边界

- 自动化测试覆盖编码后片段时长清单、AAC 端点补齐、x264 解码时间戳、可播放与不可播放结果恢复，以及单视频和批量警告界面。
- 本版本通过 TypeScript 类型检查、`172` 项 Vitest 测试和 `65` 项 Python worker 测试；另有 `16` 项因运行环境不适用而跳过。官网生产构建和 `2` 项渲染断言通过。
- 双编码器媒体集成验证为 `12` 项通过、`1` 项按编码器条件跳过，覆盖 AAC 多片段同步、x264 拼接边界、VFR、异常帧时长、解码和时间戳单调性。
- 真实 9 组回合导出在 OpenH264 与 x264 下的音画时长差分别约为 `12.9 ms` 和 `19.2 ms`，音视频 PTS/DTS 均保持单调，且未出现 Non-monotonic DTS 警告。
