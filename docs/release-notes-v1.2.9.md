# TTcut v1.2.9

**简体中文** | [English](release-notes-v1.2.9.en.md)

`v1.2.9` 是 TTcut 1.2 功能线的正式版本，新增可选高精分析，并让可变帧率视频优先在固定帧率处理媒体上完成后续流程。

## 分析精度与回合识别

- 设置新增“分析精度”。默认模式保持既有的整段视频分析；高精模式先筛选候选回合，再在扩展后的候选区间内执行更细致的二次分析。
- 高精模式的最终回合和板数仅来自二次分析结果，不会直接沿用第一阶段候选结果；因此能针对候选区间进行更精细的复核，但需要额外处理时间。
- 分析配置会在批量任务开始时固定，避免同一批任务混用不同精度设置。
- 优化回合识别的候选区间整理、进度阶段和设置默认值；既有保存设置保持不变。

## 可变帧率视频处理

- 标定始终使用原始视频。检测到可变帧率后，应用会优先生成带精确目标帧率的固定帧率处理媒体。
- 新分析的分析、预览、剪辑和新建 Premiere XML 使用处理媒体；原始视频继续作为历史身份、标定依据、封面和默认输出命名的来源。
- 处理媒体按源文件指纹和目标帧率缓存，并在失败、取消或不再被历史记录引用时清理。
- 空间不足、转码失败或输出校验失败时，应用会显示原因并回退使用原始可变帧率视频继续分析；取消和退出不会静默回退。

## 范围说明

- 本版本不提供统一的量化准确率百分比。实际识别结果仍会受到视频画面、标定质量、选择的分析精度和本机环境影响。
- 安装包继续使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单。未信任该证书的 Windows 环境仍可能显示“未知发布者”或 SmartScreen 提示。
