# TTcut v1.1.1

**简体中文** | [English](release-notes-v1.1.1.en.md)

`v1.1.1` 是 TTcut 1.1 功能线的稳定补丁版本，集中完善打包更新识别、多视频入口、批量标定恢复和安装脚本兼容性。

## 打包与多视频流程

- 打包应用仅在 Windows x64、应用已打包且存在 `app-update.yml` 时启用自动更新；本地包不会再误触发更新检查。
- 已注册安装根目录与当前资源目录不一致时，正式安装包继续阻止错误布局，本地包则复用已注册组件目录。
- 上传页支持一次选择多个 MP4 文件进入批量任务，并统一了中英文多视频提示。
- 上传页新增拍摄角度指导，帮助用户在开始分析前检查球桌、机位和人物位置。

## 批量标定恢复

- 批量任务进入页面后按队列顺序自动标定视频。
- 标定失败的项目保留在队列中，可从封面进入手动四点标定并返回原队列。
- 已就绪项目可继续分析和导出，不会被等待手动标定的项目阻塞。

## 安装兼容

- 安装空间检查、默认路径选择、版本比较、旧版进程关闭、注册提交和旧版卸载辅助脚本改用 PowerShell 2 可用语法。
- 官方发布仍以 Windows x64 为主。PowerShell 2 语法兼容不代表对所有旧版 Windows、Windows Server、x86 或 ARM64 环境的完整支持。

## 下载与校验

- 下载 `TTcut-1.1.1-x64-Setup.exe`。
- 使用同一 Release 中的 `SHA256SUMS.txt` 核对安装包、blockmap、更新元数据和 SBOM。
- `latest.yml` 使用稳定 `latest` 通道，供现有正式版更新器发现本版本。

正式安装包、卸载器和主程序使用 `CN=weiye` 自签名 Authenticode 证书并带 RFC 3161 时间戳。该证书不受 Windows 公共信任根信任，系统仍可能显示未知发布者或 SmartScreen 提示。
