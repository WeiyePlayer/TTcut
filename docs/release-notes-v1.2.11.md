# TTcut v1.2.11

**简体中文** | [English](release-notes-v1.2.11.en.md)

`v1.2.11` 是 TTcut 1.2 功能线的正式版本。它新增可选的回合识别方式，并修复连续可见流程与运行资源安装过程中的若干问题。

## 回合识别方式

- 设置新增“回合识别方式”。默认“落台判定”保留既有行为；可选“连续可见”适用于落台事件不足但球在一段时间内持续可见的画面。
- 连续可见方式固定使用完整分析，不使用高精两阶段流程；“精彩回合”按时长档位筛选，而不是按板数筛选。
- 分析结果会保存实际使用的识别方式。历史记录和自定义时间轴据各自结果显示板数或时长信息，不依赖当前设置。

## 问题修复

- 修复连续可见方式在视频末段、短而明确的回合和小球画面中容易漏检或误滤的问题。
- 修复运行资源安装阶段解压后偶发文件句柄占用，导致暂存目录重命名失败的问题。

## 安装包

- Release 同时提供完整安装包和在线安装包。在线安装包会在安装阶段下载并校验必需运行资源，需要保持联网；完整安装包适合希望一次完成安装的场景。

## 范围说明

- 本版本不提供统一的量化准确率百分比。实际识别结果仍会受到视频画面、标定质量、所选回合识别方式和本机环境影响。
- 安装包继续使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单。未信任该证书的 Windows 环境仍可能显示“未知发布者”或 SmartScreen 提示。

## 验证

- `npm run typecheck` 通过；串行 Vitest：46 个文件通过、255 个测试通过，3 个文件和 17 个测试按条件跳过。
- Worker 测试：85 个通过；官网构建和渲染测试：2 个通过。
- 正式构建将校验完整安装包仅包含 `blurball_best.pt` 与球桌权重；本地 TrackNet 权重不会随包分发，且打包态不会启用本地 TrackNet 配置。
- 完整安装包和在线安装包将完成固定 `CN=weiye` 证书签名、更新清单签名、安装包结构与模型交付边界校验。
