# TTcut v1.2.6

**简体中文** | [English](release-notes-v1.2.6.en.md)

`v1.2.6` 是 TTcut 1.2 功能线的正式版本，重点改进自定义剪辑的分段导出和 Premiere Pro 工作流，同时保留合并 MP4 的默认行为。

## 自定义回合分段导出

- 自定义模式可以把选中的每个回合分别导出为独立 MP4 文件，也可以继续生成合并后的 MP4。
- 合并 MP4、独立回合视频和 Premiere XML 可以单独或同时启用；未启用的产物不会触发对应的编码或文件写入。
- 每次导出使用独立、冲突安全的输出目录，避免覆盖源视频或已有结果；取消导出时会清理本次临时产物。
- 当多个产物中只有部分成功时，界面会保留已生成结果并报告部分成功状态，便于定位输出目录。

## Premiere Pro XML 与声道关联

- 新增 Premiere Pro 可导入的 FCP7 `xmeml` v4 XML。XML 引用原始视频，并为每个选中的回合写入可编辑的入点和出点。
- XML 使用连续的视频轨道和与源媒体声道数匹配的音频轨道；单声道、双声道和无音频媒体分别生成正确的媒体关联。双声道源会正确关联 A1/A2 音频轨道。
- XML 不是原生 `.prproj`、AAF 或 FCPXML 工程文件。移动源视频后，需要在 Premiere 中重新链接媒体。

## 时间轴与品牌

- 改进自定义时间轴对短片段的边界拖动，保留独立的可操作边缘区域，便于精确调整起止位置。
- 统一更新 TTcut 应用、安装包和官网使用的品牌图标资源。

## 范围说明

- 本版本的主要变化位于自定义导出、XML 生成、时间轴交互和品牌资源；没有改变模型权重、动态 ROI、球识别、回合识别或板数识别算法。
- v1.2.5 的 BlurBall 默认模型、可选 TrackNet 模型和批量任务稳定性修复继续保留。
- 安装包继续使用固定 `CN=weiye` 自签名 Authenticode 证书、RFC 3161 时间戳和签名更新清单。未信任该证书的 Windows 环境仍可能显示“未知发布者”或 SmartScreen 提示。
