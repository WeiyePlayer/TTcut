# 03: 用户任务结束后自动恢复预览

**What to build:** 预览被抢占或因 TASK_BUSY 推迟后，当前用户任务一结束（完成、失败或取消），仍在页面上的视频自动重新生成兼容预览。主进程在任务位空出时广播"任务空闲"事件，经 preload 受限接口传给界面；页面已卸载或视频源已切换时不触发。

**Blocked by:** 01 预览给用户发起的任务让路；02 预览在后台静默进行

**Status:** ready-for-agent

- [ ] 最后一个用户任务结束时广播一次空闲事件（processes 测试）
- [ ] 只有被推迟过的预览在收到事件后重新调用准备预览，且只调用一次（组件测试）
- [ ] 卸载或切换视频源后不再重试
- [ ] typecheck 通过
- [ ] 真实 Mac HDR 视频"自定义页导出 → 结束后预览自动恢复"单独记录证据；未执行则标注未验证
