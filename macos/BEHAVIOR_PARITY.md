# Windows baseline → macOS behavior map

Baseline: `b9e359b3b7ea113dd5b23f203b03e53fb7690d88`. This map describes implementation and evidence, not real-footage quality acceptance.

| Area | Preserved behavior / intentional change | Native implementation | Evidence |
|---|---|---|---|
| Layout/navigation | Auto Cut and History sidebar, Settings below; collapsed sidebar in custom editing | `Views.swift`, `CustomWorkspace.swift` | Own-view screenshots, navigation UITest available |
| Inputs | Single and multiple video selection; drag/drop local URLs; multiple inputs enter batch | `AppState.acceptVideos`, `DropCard` | Workflow loading tests; drag gesture remains in interactive test scope |
| Calibration | First-frame preview; 4 corners; reset, zoom and drag; automatic five-position table inference; manual fallback | `CalibrationView.swift`, native worker, `TableAggregation.swift` | Original preprocessing fixture, model numeric check, native table invocation; manual UI test available |
| Ball/table models | Same BlurBall and table weights/architecture; native Core ML replaces Windows Python/CUDA runtime | Worker, native bridge, conversion scripts | Both output-tensor comparisons pass fixed tolerances |
| Analysis | Full and two-stage analysis; original ROI, temporal windows, thresholds, tracking, bounce and rally grouping | Worker, `Geometry`, `BounceDetector`, `Segments` | 60 original Python trajectory cases / 240 bounces; native full/two-stage tests |
| Modes | All rallies, highlights strictly greater than 3/5/7 bounces, custom | `Segments`, `ReviewView`, `CustomWorkspace` | Domain tests, rendered views |
| Custom editing | Include/exclude, edge trim, selection restore constraints, manual insertion, delete and renumber, preview/seek, timeline zoom | `Clips`, `ClipTimeline`, `PlaybackController` | Domain fixtures and application workflow; native player readiness/seek test |
| Export | Merged MP4; separate selected rally MP4 plus optional FCP7 xmeml XML; success folder and continue editing | `MediaExporter`, `PremiereXML`, completion view | Synthetic MP4/XML tests and application workflow |
| Strategies | Fast segmented default; compatible graph strategy retained internally; stream copy is only an eligible/validated optimization | `MediaExporter.merged` | Both strategies tested; no new settings switch |
| Fidelity | H264/HEVC, 8/10-bit, HDR10/HLG, static metadata, rotation/SAR, stereo/multichannel, short synthetic 8K | Probe, export, native decoder | Metadata, duration, PTS and audio sync assertions; combined 8K HEVC 10-bit HDR10 test |
| VFR | Optional CFR processing media; source identity and cache provenance retained; conversion failure reported | `MediaExporter.processing`, history leases | VFR normalization/cache test and lease cleanup test |
| Batch | Calibrate eligible items before serial analysis/export; per-item all/highlight/analyze-only, progress, failure isolation, manual recovery, results/output access | `AppState.runBatch`, `BatchView` | Real application workflow with two valid inputs, failed input and recovered item |
| History | Save analyses/covers, reopen without reanalysis, same-source replacement, source state, open export folder, delete/clear | `HistoryStore`, `HistoryView` | Persistence/recovery/quarantine tests and workflow; original/output files preserved |
| Settings | Chinese/English, automatic calibration, full/two-stage, VFR option, lead-in/out, about/contact/support, update status | `SettingsView`, localization resources | Rendered Chinese/English settings; local update tests |
| Cancellation/errors | Cancel native subprocess, drop stale progress, missing assets/source errors, partial export warnings, history-write errors do not discard output | Process runner, AppState, exporter | Cancellation, failed paths, partial XML recovery and workflow tests |
| Packaging | Xcode project, app-relative helpers/frameworks/models, arm64/macOS 15 target, ad-hoc app/DMG | Project and build/audit scripts | Release and relocation reports generated by packaging |
| Updates | Keep update feature via Sparkle; no production feed activated | `UpdateService` | Actual signed localhost update installs/relaunches; wrong signature refused |
| Removed | Component selection/download/manual import, second FFmpeg bundle, batch shutdown, Windows history import | No equivalent product flow | Source/bundle inspection |

Windows `src/`, `worker/`, existing tests, build scripts and workflows remain unchanged. The new app does not adopt the iOS product layout or TrackNet model. The installed app does not need Python, Node or Homebrew.

Real-media accuracy, sustained 8K workloads, HDR viewing on real displays, real Premiere/NLE import and macOS 15 hardware execution are separate unverified acceptance items. A native test passing on the current host does not imply those results.
